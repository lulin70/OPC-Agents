# OPC-Agents

**Version**: 2.0.0 (整改版)

> **为一人公司打造的智能工作助手。像和秘书对话一样简单，真正完成所有想完成的工作。**

## 核心理念

**OPC-Agents** 是一个为**一人公司**（OPC, One-Person Company）设计的智能工作助手系统。

通过和**总裁办**的自然对话，你可以：
- ✅ 委托工作，而不是创建任务
- ✅ 获得成果，而不是过程
- ✅ 享受服务，而不是操作工具

**你不是在操作工具，而是在委托一位专业的秘书！**

## 💼 核心场景

### 1. 发布新产品

**你说**："我想发布新产品"

**总裁办**：
```
好的！我立即安排新产品发布工作。
预计 1 个工作日完成，包括：
1. 市场调研（2 小时）- 📊 市场调研报告
2. 产品设计（3 小时）- 📋 产品需求文档
3. 营销方案（2 小时）- 📈 营销推广方案
4. 汇总评审（1 小时）- 📦 完整发布方案

现在就开始吗？
```

**最终交付**：
```
📦 工作成果 (4 项)
├─ 📊 市场调研报告
├─ 📋 产品需求文档
├─  营销推广方案
└─ 📦 新产品发布方案（完整版）
```

### 2. 撰写报告

**你说**："帮我写份市场分析报告"

**总裁办**：
```
收到！我立即安排报告撰写工作。
预计 2-4 小时完成，包括：
1. 数据收集（1 小时）
2. 数据分析（1 小时）
3. 报告撰写（1-2 小时）

需要重点关注哪些方面？
```

**最终交付**：
```
📦 工作成果
└─ 📄 专业分析报告（含数据图表、趋势分析、结论建议）
```

### 3. 组织会议

**你说**："组织一个项目讨论会"

**总裁办**：
```
好的！我来安排会议。
预计 30 分钟完成，包括：
1. 时间协调（15 分钟）
2. 发送邀请（5 分钟）
3. 材料准备（30 分钟）

请问会议主题和参会人员？
```

**最终交付**：
```
📦 工作成果
├─ 📅 会议时间安排
├─ 📧 会议邀请（已发送）
└─ 📁 会议材料包（议程、背景资料、讨论要点）
```

## 🤖 总裁办人格

### 人格特征

- **名称**：总裁办秘书
- **定位**：您的专属工作助手
- **语气**：专业而温暖
- **风格**：主动、细致、高效
- **原则**：
  1. 凡事有交代 - 每个任务都有始有终
  2. 主动不被动 - 提前思考，主动汇报
  3. 结果导向 - 关注交付质量，不只是过程
  4. 简单高效 - 不让您思考，一站式解决
  5. 持续学习 - 记住您的偏好，越用越懂你

### 对话风格

**接受任务**：
> "好的，我立即安排！预计 {duration} 内完成。"

**进度汇报**：
> "向您汇报：{task_name} 当前进度 {progress}%，预计 {eta} 完成。"

**任务完成**：
> "任务已完成！这是交付成果，请过目。"

**遇到问题**：
> "遇到一个问题需要您决策：{issue}。我的建议是 {suggestion}。"

**主动提醒**：
> "提醒您：{task_name} 截止日期是 {deadline}，目前进度 {progress}%。"

## 🏷️ 标签化管理

### 灵活的标签系统（替代固定部门）

**4 个维度**：

1. **任务类型** (10 种)
   - 🔍 调研 | 🎨 设计 | 💻 开发 | 📝 文案
   - 📊 分析 | 🧪 测试 | 👥 会议 | 📄 文档
   - ✅ 评审 | 📅 规划

2. **优先级** (4 级)
   - 🔥 紧急 (2 小时)
   - ⭐ 重要 (24 小时)
   - 📌 常规 (3 个工作日)
   - 🐢 低优 (1 周)

3. **技能** (8 种)
   - 💬 沟通 | ✍️ 写作 | 🎨 设计
   - 👨‍💻 编程 | 🔬 分析 | 📚 研究
   - 🎤 演讲 | 📊 管理

4. **业务域** (8 个)
   - 📦 产品 | 📢 营销 | 💰 销售
   - 👥 人事 | 💵 财务 | 📈 运营
   - 🛟 支持 | 🎯 战略

### 智能标签推荐

**系统推荐**：

## 🎨 界面设计

### 对话中心

- **拟人化问候**："您好！我是总裁办秘书，今天有什么工作要委托给我吗？"
- **自然对话流**：像微信聊天一样简单
- **任务卡片嵌入**：对话中显示任务进度和成果
- **实时反馈**：进度更新、完成通知

### 工作成果区

- **卡片式展示**：图标分类、清晰美观
- **一键操作**：查看、下载、分享
- **成果统计**：已完成 X 项
- **自动归档**：历史成果可追溯

### 响应式设计

- **桌面端**：完整功能，多栏布局
- **平板端**：侧边栏折叠
- **移动端**：单栏布局，触摸友好

## 🚀 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置系统

```bash
# 复制配置文件模板
cp config.toml.sample config.toml

# 编辑配置文件，设置 API 密钥等
```

### 启动系统

```bash
# 使用启动脚本
./OPCstart.sh

# 或直接运行
python web_interface/app.py
```

### 访问界面

打开浏览器访问：`http://localhost:5009`
