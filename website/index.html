五大核心技能

把每一个运营环节做到真正好用

围绕一人公司高频场景，每个技能都从输入到输出闭环，拒绝半成品。

邮件

Email 技能

收发邮件、智能分类、自动回复草稿、附件归档。把邮箱从信息噪音变成结构化任务流。

  • IMAP / SMTP 主流服务商接入
  • 关键邮件自动归类与提醒
  • 草稿生成与一键发送
财务

Finance 技能

记账、收支流水、发票与报表生成。让一人公司也能拥有专业财务视角。

  • 本地 SQLite 存储财务数据
  • 发票录入与 Excel 导出
  • 月度 / 季度现金流报表
报告

Report 技能

周报、月报、客户简报自动生成。支持 Word / Excel / PDF 多格式导出。

  • 结构化模板驱动生成
  • 多语言切换（中 / 英 / 日）
  • 三贤者共识保证内容质量
任务

Task Manager 技能

任务拆解、依赖管理、并行执行、进度追踪。让模糊的需求变成清晰的待办清单。

  • 并行执行降低 3 倍延迟
  • 关键决策前置共识保护
  • 异步任务可恢复与撤销
CRM

CRM 技能

客户档案、跟进记录、机会管理。把零散的沟通聚合成可复盘的客户资产。

  • 本地化客户档案库
  • 跟进时间线一目了然
  • 与邮件 / 报告技能联动

开始体验

三种安装方式

选一种适合你的方式开始

基础版在用户本地运行，所有业务数据存储在本机，不上云。

推荐

PyPI 安装

适合已具备 Python 3.10+ 环境的用户

pip install opc-agents
opc-agents

安装后命令 opc-agents 即可启动。

一键脚本

脚本安装

适合非技术用户，自动检测环境并配置

pip install opc-agents && opc-agents

从 PyPI 安装，自动创建虚拟环境与默认配置。

容器化

Docker 安装

适合偏好容器隔离的用户

docker run -d \
  --name opc-agents \
  -p 8000:8000 \
  -v ~/.opc-agents:/root/.opc-agents \
  ghcr.io/opc-agents/opc-agents:latest

容器运行在用户本机，监听 localhost:8000。

基础版仅在用户本地运行，禁止部署到云端服务器。 专业版网关由官方统一部署在云端，用户通过 License Key 激活。
