# OPC-Agents 故障排除指南

## 1. 常见问题与解决方案

### 1.1 Web界面无法访问

**症状**：无法访问 `http://localhost:5000`

**可能原因**：
- 服务未启动
- 端口被占用
- 防火墙阻止
- 网络连接问题

**解决方案**：
1. **检查服务状态**：
   ```bash
   # Linux/macOS
   ps aux | grep python
   
   # Windows
   tasklist | findstr python
   ```

2. **检查端口占用**：
   ```bash
   # Linux/macOS
   lsof -i :5000
   
   # Windows
   netstat -ano | findstr :5000
   ```

3. **检查防火墙设置**：
   - 确保端口5000已开放
   - 暂时关闭防火墙测试

4. **检查网络连接**：
   - 尝试访问 `http://127.0.0.1:5000`
   - 检查网络设置

### 1.2 代理性能不佳

**症状**：代理响应慢、回答质量差

**可能原因**：
- AI模型配置不当
- 系统资源不足
- 代理技能缺失
- 网络连接问题

**解决方案**：
1. **优化模型配置**：
   - 使用更强大的AI模型
   - 调整模型参数

2. **检查系统资源**：
   - 增加内存和CPU资源
   - 关闭不必要的进程

3. **分析代理性能**：
   ```bash
   python3 cli/cli.py agent analyze agent_id
   ```

4. **生成改进计划**：
   ```bash
   python3 cli/cli.py agent optimize agent_id
   ```

### 1.3 技能注册失败

**症状**：无法注册新技能

**可能原因**：
- 技能路径错误
- 技能文件格式不正确
- 权限不足
- MCP连接失败

**解决方案**：
1. **检查技能路径**：
   - 确保路径存在且可访问
   - 检查文件权限

2. **验证技能格式**：
   - 检查技能文件是否符合要求
   - 查看技能文件结构

3. **检查MCP连接**：
   ```bash
   python3 cli/cli.py mcp fetch-skills
   ```

4. **检查日志**：
   - 查看 `logs/skill.log` 中的错误信息

### 1.4 API认证失败

**症状**：API请求返回401错误

**可能原因**：
- API密钥错误
- 认证头格式错误
- 密钥过期

**解决方案**：
1. **检查API密钥**：
   - 确认API密钥正确
   - 检查环境变量设置

2. **验证认证头**：
   - 确保认证头格式为 `Bearer <api_key>`
   - 检查请求头设置

3. **重置API密钥**：
   - 在 `config/system.json` 中更新API密钥
   - 重启系统

### 1.5 模型连接失败

**症状**：无法连接到AI模型

**可能原因**：
- API密钥错误
- 网络连接问题
- 模型服务不可用
- 配置错误

**解决方案**：
1. **检查API密钥**：
   - 确认API密钥有效
   - 检查模型配置

2. **测试网络连接**：
   ```bash
   ping api.openai.com
   ```

3. **检查模型状态**：
   ```bash
   python3 cli/cli.py model list
   ```

4. **查看日志**：
   - 查看 `logs/model.log` 中的错误信息

## 2. 日志分析

### 2.1 日志位置

- **系统日志**：`logs/system.log`
- **API日志**：`logs/api.log`
- **代理日志**：`logs/agent.log`
- **模型日志**：`logs/model.log`
- **技能日志**：`logs/skill.log`

### 2.2 日志级别

- **DEBUG**：详细调试信息
- **INFO**：一般信息
- **WARNING**：警告信息
- **ERROR**：错误信息
- **CRITICAL**：严重错误

### 2.3 日志分析工具

- **Linux/macOS**：
  ```bash
  # 查看错误日志
  grep ERROR logs/*.log
  
  # 实时查看日志
  tail -f logs/system.log
  ```

- **Windows**：
  ```cmd
  # 查看错误日志
  findstr ERROR logs\*.log
  
  # 实时查看日志
  powershell -command "Get-Content logs\system.log -Wait"
  ```

## 4. 常见错误代码

### 4.1 HTTP错误码

| 错误码 | 描述 | 可能原因 | 解决方案 |
|--------|------|----------|----------|
| 400 | Bad Request | 请求参数错误 | 检查请求参数 |
| 401 | Unauthorized | 认证失败 | 检查API密钥 |
| 403 | Forbidden | 权限不足 | 检查权限设置 |
| 404 | Not Found | 资源不存在 | 检查URL路径 |
| 500 | Internal Server Error | 服务器内部错误 | 查看日志 |
| 502 | Bad Gateway | 网关错误 | 检查网络连接 |
| 503 | Service Unavailable | 服务不可用 | 检查服务状态 |

### 4.2 系统错误码

| 错误码 | 描述 | 解决方案 |
|--------|------|----------|
| 1001 | 模型连接失败 | 检查模型配置和网络连接 |
| 1002 | 技能加载失败 | 检查技能路径和权限 |
| 1003 | 代理初始化失败 | 检查代理配置 |
| 1004 | 数据库连接失败 | 检查数据库配置 |
| 1005 | 配置文件错误 | 检查配置文件格式 |

## 5. 恢复与备份

### 5.1 数据备份

**手动备份**：
```bash
# 备份配置
cp -r config/ config_backup/

# 备份日志
cp -r logs/ logs_backup/

# 备份数据
cp -r data/ data_backup/
```

**自动备份**：
创建备份脚本 `backup.sh`：
```bash
#!/bin/bash
BACKUP_DIR="backup_$(date +%Y%m%d_%H%M%S)"
mkdir -p $BACKUP_DIR
cp -r config/ $BACKUP_DIR/
cp -r data/ $BACKUP_DIR/
tar -czf $BACKUP_DIR.tar.gz $BACKUP_DIR
rm -rf $BACKUP_DIR
echo "Backup completed: $BACKUP_DIR.tar.gz"
```

### 5.2 系统恢复

**从备份恢复**：
```bash
# 停止服务
# 恢复配置
cp -r backup/config/ config/
# 恢复数据
cp -r backup/data/ data/
# 启动服务
```

**重置系统**：
```bash
# 停止服务
# 重置配置
cp -r config_default/ config/
# 清空数据
rm -rf data/*
# 启动服务
```
