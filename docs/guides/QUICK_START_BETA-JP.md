## 📦 クイックインストール（5分）

### 方法1：pipインストール（最も簡単）

```bash
pip install opc-agents
opc-agents
```

> 初回利用時はAPIキーの設定が必要：作業ディレクトリに`.env`ファイルを作成し、`MOKA_API_KEY=your-key`を入力

### 方法2：ソースインストール（カスタマイズ可能）

#### 1. プロジェクトをクローン

```bash
git clone https://github.com/lulin70/OPC-Agents.git
cd OPC-Agents
```

#### 2. 依存パッケージをインストール

**方法A：ワンクリックインストール（推奨）**
```bash
chmod +x install.sh start.sh
./install.sh
```

**方法B：手動インストール**
```bash
# 仮想環境を作成（推奨）
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 依存パッケージをインストール
pip install -r requirements.txt
```

#### 3. APIキーの設定（オプション・推奨）

```bash
# 設定テンプレートをコピー
cp .env.example .env

# .envファイルを編集し、APIキーを入力
# 以下のいずれかをサポート：
# - MOKA_API_KEY（推奨、複数モデル対応）
# - GLM_API_KEY（Zhipu AI）
# - OPENAI_API_KEY（OpenAI）
# - OLLAMA_BASE_URL（Ollamaローカルモデル、例: http://localhost:11434）
# - OLLAMA_ENABLED=true（Ollamaを有効化、BASE_URL未設定時はデフォルトURL使用）
# - OLLAMA_MODEL=llama3（Ollamaモデル名、デフォルトllama3）
```

**APIキーがない？** 問題ありません！システムは自動的にテンプレートモードにフォールバックし、引き続き使用可能です。

#### 4. システムを起動

```bash
./start.sh
```

ブラウザが自動的に `http://localhost:8501` を開きます

## ⚠️ Beta版の既知の制限

### 現在のバージョンの制限

1. **検索機能**
   - DuckDuckGoに依存、時折失敗する可能性あり
   - 利用不可時はナレッジベースに自動フォールバック
   - 基本的な使用には影響なし

2. **LLM機能**
   - AI拡張モードにはAPIキーが必要
   - APIキーなしではテンプレートモード（品質はやや低いが使用可能）

3. **コンテンツ品質**
   - 生成されたコンテンツは人間のレビューが必要
   - 初稿として使用し、実際のニーズに合わせて調整することを推奨

### 起動時のメッセージ

起動時に以下のメッセージが表示される場合があります — **これは正常です**：

- APIキー検出 → 「🤖 AI拡張モード」と表示
- APIキー未検出 → 「📝 テンプレートモード」と表示（機能は正常、コンテンツ品質はやや低い）

## 🐛 問題が発生した場合

### よくある質問

#### Q1: 起動に失敗し、依存パッケージ不足と表示
```bash
# 解決策：依存パッケージを再インストール
pip install --upgrade -r requirements.txt
```

#### Q2: 検索機能が動作しない
```
原因: ネットワーク問題またはDuckDuckGoのレート制限
影響: システムは自動的にナレッジベースにフォールバック
提案: 後でもう一度試すか、ネットワーク接続を確認
```

#### Q3: LLM初期化に失敗
```
原因: APIキーが未設定
影響: テンプレートモードを使用（品質はやや低い）
提案: .envファイルにAPIキーを設定
```

#### Q4: 生成されたコンテンツが一般的すぎる
```
原因: 検索失敗 + LLM未設定
提案:
1. APIキーを設定してAI拡張を有効化
2. より具体的な入力情報を提供
3. 生成されたコンテンツを手動で調整
```
