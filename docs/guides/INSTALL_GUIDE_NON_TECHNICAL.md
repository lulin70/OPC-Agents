## §1 什么是 OPC-Agents

### 1.1 一句话介绍

**OPC-Agents 是你的 AI 助手，帮你发邮件、记账、写报告、管客户。**

你只要用大白话告诉它想做什么，它就帮你把事情做完。比如你说"给张总发跟进邮件"，它会自动写好邮件、找好收件人、点发送；你说"记一笔收入 3000 元"，它会自动记到账本里、分类、生成报表。

### 1.2 四个核心场景

| 你说什么 | OPC-Agents 做什么 |
|---------|-----------------|
| 给张总发跟进邮件 | 自动写好邮件内容，填好收件人，等你确认后发出 |
| 记一笔收入 3000 元 | 自动记账、分类到"咨询收入"、更新本月报表 |
| 本月经营报告 | 自动汇总收入支出、客户情况、生成 PDF 报告 |
| 新增客户王总 | 自动录入客户档案、创建跟进任务、设置提醒 |

每个场景都不需要你打开多个软件来回切换。你只要在一个对话框里输入需求，剩下的交给 OPC-Agents。

### 1.3 与常用工具的对比

| 对比维度 | Excel / WPS 表格 | Notion / 印象笔记 | ChatGPT 网页版 | OPC-Agents |
|---------|-----------------|------------------|---------------|-----------|
| 数据存储位置 | 本地文件 | 云端服务器 | 云端服务器 | 你的电脑本地，不上云 |
| AI 智能程度 | 无 AI，纯手工 | 基础 AI 辅助 | 强 AI 但无记忆 | 强 AI + 跨会话记忆 |
| 自动化能力 | 公式 + 宏 | 模板 + 提醒 | 只能对话，不能动手 | 自动发邮件、记账、生成报告 |
| 学习成本 | 高（要学函数） | 中（要搭结构） | 低（直接对话） | 低（直接对话，且有引导） |
| 数据隐私 | 本地较安全 | 数据上云有风险 | 对话内容上云 | 全部数据存你电脑，零泄露 |

**一句话总结**：Excel 让你手工做事，Notion 让你整理资料，ChatGPT 让你聊天，**OPC-Agents 替你做事**。

### 1.4 数据安全承诺

我们理解你对客户数据安全的担心。OPC-Agents 做出以下承诺：

1. **所有数据存在你的电脑上**：客户名单、邮件记录、财务数据、对话历史，全部存在你的电脑硬盘里，不会上传到任何云端服务器。
2. **API Key 加密存储**：如果你使用云端 AI（如 MOKA、智谱 GLM），你的 API Key 会用银行级别的 AES 加密算法存在本地，别人即使偷走你的电脑也看不到。
3. **不上报任何使用数据**：除非你主动在"设置 → 反馈"里提交反馈，否则我们不会收到你的任何使用信息。
4. **可随时导出和删除**：你的数据随时可以一键导出为 ZIP 备份，也可以一键清空，不留任何痕迹。
5. **代码完全开源**：所有代码在 https://github.com/lulin70/OPC-Agents 公开，欢迎任何技术人员审查我们的安全承诺是否兑现。

## §2 安装前准备（5 分钟检查清单）

在开始安装之前，请花 5 分钟检查你的电脑是否满足要求。准备充分了，安装过程才会顺利。

### 2.1 硬件要求

| 项目 | 最低要求 | 推荐配置 | 如何查看 |
|------|---------|---------|---------|
| 电脑类型 | Mac 或 Windows 均可 | Mac M1 及以上 / Windows 11 | 看电脑外壳 |
| 内存 | 4 GB 以上 | 8 GB 以上 | Mac：左上角苹果图标 → 关于本机；Windows：设置 → 系统 → 关于 |
| 磁盘空间 | 5 GB 可用空间 | 10 GB 可用空间 | Mac：关于本机 → 储存空间；Windows：我的电脑 → C 盘属性 |
| 网络连接 | 稳定的宽带 | 10 Mbps 以上 | 打开浏览器能正常访问网页即可 |

> **小白说明**（浅米色 #D4C5A9）：
> "内存"和"磁盘空间"不是一回事。内存是电脑工作时用的"工作台"，磁盘是存东西的"柜子"。两个都要够大，OPC-Agents 才能跑得顺。

### 2.2 软件要求

#### 2.2.1 Python 3.10 或更高版本

OPC-Agents 是用 Python 这门编程语言写出来的。你的电脑需要先装 Python，OPC-Agents 才能运行。

**如何检查是否已安装 Python**：

最简单的方法是直接运行 OPC-Agents 安装包（见 §3 Step 2），安装程序会自动检测。如果弹出"Python 未找到"提示，说明你需要按下面的步骤安装。

如果你想自己提前确认：

- **Mac 用户**：打开"启动台" → "其他"文件夹 → "终端"应用，输入 `python3 --version` 后按回车键。如果显示 `Python 3.10.x` 或更高版本号，说明已安装。
- **Windows 用户**：按键盘 `Win + R` 键，在弹出的小窗口输入 `cmd` 后按回车键，然后在弹出的黑色窗口里输入 `python --version` 后按回车键。如果显示 `Python 3.10.x` 或更高版本号，说明已安装。

如果上述操作让你觉得复杂，**完全可以跳过这一步**，直接进入 §3 安装步骤。安装程序会自动帮你检测和提示。

**如果没有安装，或版本低于 3.10**：

1. 打开浏览器，访问 https://www.python.org/downloads/
2. 点击页面上的大黄色按钮 "Download Python 3.x.x"（自动识别你的系统）
3. 下载完成后，双击安装包
4. **重要**：在安装向导的第一页，**务必勾选 "Add Python to PATH"** 这个复选框（在窗口底部），然后再点 "Install Now"
5. 等待大约 1 分钟，看到 "Setup was successful" 提示后点 "Close"

![Python 下载页面](../assets/images/install-python-download.png)

![Python 安装勾选 PATH](../assets/images/install-python-path.png)

> **重要提醒**（灰粉色 #C9A9A6）：
> 如果你忘了勾选 "Add Python to PATH"，安装完后 OPC-Agents 会提示"Python 未找到"。解决办法：卸载 Python 重新安装，这次记得勾选。卸载方法：Mac 直接把应用拖到废纸篓；Windows 在"设置 → 应用"里找到 Python 卸载。

#### 2.2.2 网络连接

安装过程需要下载约 200 MB 的安装包和组件，使用过程也需要联网与 AI 对话。请确保：

- 网络稳定，不会中途断线
- 如果在公司网络，可能需要让 IT 同事放行 `api.moka-ai.com` 域名（OPC-Agents 通过 PromiseLink Pro 网关 `gateway.promiselink.cn` 调用 Moka AI，但该网关地址对用户透明）
- 如果使用 Ollama 本地方案（见 §2.3 选项 A），首次下载模型需要 5-10 GB 流量

### 2.3 AI 后端选择（三选一）

OPC-Agents 本身是"手脚"，它需要一个"大脑"来思考和生成内容。这个"大脑"就是 AI 后端。我们提供三个选择，按推荐顺序排列。

#### 选项 A：Ollama（本地免费，推荐配置好的电脑）

**适合谁**：

- 电脑内存 16 GB 以上（最好是 Mac M1/M2/M3 系列）
- 不想花钱订阅 AI 服务
- 对数据隐私有极高要求，连对话都不想发到云端
- 愿意等待首次下载模型（5-10 分钟）

**优点**：

- 完全免费，零月费
- 所有 AI 对话都在你的电脑上完成，绝对隐私
- 断网也能用

**缺点**：

- 首次下载模型耗时（5-10 分钟，看网速）
- 对电脑配置要求高，低配电脑运行会慢
- AI 智能程度略低于云端模型（约 GPT-3.5 水平）

**安装步骤**：

1. 打开浏览器访问 https://ollama.com/download
2. 下载对应你系统的安装包（Mac 或 Windows）
3. 双击安装包，按提示完成安装（约 1 分钟）
4. 安装完成后，Ollama 会在后台运行（菜单栏会出现一个小羊驼图标）
5. 不需要做其他操作，OPC-Agents 会自动识别并使用

![Ollama 下载页面](../assets/images/install-ollama-download.png)

#### 选项 B：MOKA AI（云端付费，推荐新手）

**适合谁**：

- 电脑配置一般（4-8 GB 内存）
- 愿意为高质量 AI 输出付费（约 50 元/月起）
- 希望立即开始使用，不想等模型下载
- 需要 Claude Sonnet 4 级别的强 AI（写邮件、做报告质量更高）

**优点**：

- AI 智能强，输出质量高（接近 Claude Sonnet 4 水平）
- 启动快，配置好 API Key 立即可用
- 不占你电脑资源
- 支持多种模型切换

**缺点**：

- 需要付费（按用量计费，约 50-200 元/月，看你的使用频率）
- AI 对话内容会发到 MOKA 服务器（但不会存储，处理完即删）
- 需要联网才能用

**获取 API Key 步骤**：

1. 打开浏览器访问 https://moka-ai.com
2. 点击右上角"注册"，用手机号或邮箱注册账号
3. 登录后点击右上角你的头像 → "API Keys"
4. 点击"创建新 Key"按钮，给它起个名字（比如"OPC-Agents"）
5. 复制生成的密钥（格式像 `sk-moka-xxxxxxxx`），**立即保存到安全的地方**（推荐 1Password 或 Bitwarden 密码管理器）
6. 这串密钥就是 API Key，安装 OPC-Agents 时会用到

![MOKA 注册页面](../assets/images/install-moka-register.png)

![MOKA 获取 API Key](../assets/images/install-moka-apikey.png)

> **重要提醒**（灰粉色 #C9A9A6）：
> API Key 只在创建时显示一次，关闭页面后就再也看不到了。如果丢了只能重新创建。所以**创建后立即复制保存**。

#### 选项 C：智谱 GLM-4（云端免费额度）

**适合谁**：

- 想先免费试用一段时间再决定
- 电脑配置一般
- 不介意用国产 AI 模型
- 主要使用中文场景

**优点**：

- 有免费额度（每月 100 万 token，足够日常使用）
- 中文理解能力强
- 注册简单，手机号即可

**缺点**：

- AI 综合智能略低于 MOKA 的 Claude Sonnet 4
- 免费额度用完后需要付费
- 复杂任务（如长报告生成）质量略逊

**获取 API Key 步骤**：

1. 打开浏览器访问 https://open.bigmodel.cn
2. 点击右上角"登录/注册"，用手机号注册
3. 登录后点击右上角你的头像 → "API Keys"
4. 点击"添加 API Key"按钮
5. 复制生成的密钥（格式像 `xxxxxxxx.xxxxxxxx`），**立即保存**
6. 这串密钥就是 API Key，安装时用

![智谱 GLM 注册](../assets/images/install-glm-register.png)

## §3 安装步骤（图文版，5 步）

现在开始正式安装。整个过程大约 20 分钟，请按顺序操作。

### Step 1: 下载安装包

**方式 A（推荐）：从 PyPI 安装（pip install）**

OPC-Agents 是 PyPI 开源包，打开"终端"（Mac）或"命令提示符"（Windows），执行一行命令即可安装：

```bash
pip install opc-agents
```

- 安装过程自动完成，约 1-2 分钟看网速
- 安装后会自动创建虚拟环境与默认配置
- 无需访问任何官网，直接从 Python 官方包仓库下载

![pip 安装示意图](../assets/images/install-step1.png)

**方式 B（备用）：从 GitHub 仓库下载源码**

1. 打开浏览器访问 https://github.com/lulin70/OPC-Agents
2. 点击"Code"按钮，选择"Download ZIP"
3. 解压后进入目录，执行 `pip install -e .`

**下载后做什么**：

- **Mac 用户**：终端执行 `pip install opc-agents`，完成后执行 `opc-agents start`
- **Windows 用户**：命令提示符执行 `pip install opc-agents`，完成后执行 `opc-agents start`

> **如果失败的应对方法**（灰粉色 #C9A9A6）：
> - 下载速度很慢？配置 PyPI 国内镜像源：`pip install opc-agents -i https://pypi.tuna.tsinghua.edu.cn/simple`
> - pip 命令找不到？先安装 Python 3.10+（见 §2.1 系统要求）
> - 权限错误？Mac/Linux 用户加 `--user` 参数：`pip install --user opc-agents`
> - 实在下不了？在 [GitHub Issues](https://github.com/lulin70/OPC-Agents/issues) 提交问题，我们会尽快回复

### Step 2: 运行安装程序

#### Mac 用户

1. 打开"访达" → "下载"文件夹
2. 找到 `OPC-Agents-x.x.x.pkg` 文件，双击打开
3. 安装向导会弹出，点击"继续"
4. 阅读许可协议，点击"同意"
5. 选择安装位置（默认即可，不用改），点击"安装"
6. 系统会要求输入你的 Mac 登录密码，输入后点"安装软件"
7. 等待大约 30 秒，看到"安装成功"提示后点"关闭"

![Mac 安装向导](../assets/images/install-step2-mac.png)

#### Windows 用户

1. 打开"文件资源管理器" → "下载"文件夹
2. 找到 `OPC-Agents-Setup-x.x.x.exe` 文件，双击打开
3. 如果弹出"用户账户控制"窗口问"是否允许此应用更改你的设备"，点击"是"
4. 安装向导弹出，点击"下一步"
5. 阅读许可协议，勾选"我接受协议"，点击"下一步"
6. 选择安装位置（默认即可），点击"下一步"
7. 选择开始菜单文件夹（默认即可），点击"下一步"
8. 勾选"在桌面创建快捷方式"，点击"下一步"
9. 点击"安装"按钮，等待大约 1 分钟
10. 看到"完成 OPC-Agents 安装向导"提示，勾选"启动 OPC-Agents"，点击"完成"

![Windows 安装向导](../assets/images/install-step2-windows.png)

**安装完成后**：

- 桌面会出现 "OPC-Agents" 图标（蓝绿色圆形 logo）
- Mac 用户还可以在"启动台"找到它

> **如果失败的应对方法**（灰粉色 #C9A9A6）：
> - Mac 提示"无法验证开发者"？见 §5 FAQ 第 1 题
> - Windows 杀毒软件报警？见 §5 FAQ 第 2 题

> - 提示"磁盘空间不足"？清理一下 C 盘，至少留 5 GB 空间

> **做得好！你已完成第 2 步**（灰绿色 #9CAF9A）
> 安装包已经装到电脑上了。接下来我们要第一次启动它。

### Step 3: 首次启动

1. 在桌面找到 "OPC-Agents" 图标，**双击**启动
2. 等待大约 5-10 秒，会看到一个加载画面（蓝色进度条）
3. 首次启动会弹出"数据采集同意"对话框

![首次启动加载画面](../assets/images/install-step3-loading.png)

#### 关于"数据采集同意"对话框

这个对话框有 4 个复选框，每个的含义如下：

| 选项 | 含义 | 默认状态 | 我们的建议 |
|------|------|---------|-----------|
| 1. 必要功能运行数据 | 记录应用是否正常运行、崩溃信息 | 默认勾选（必须） | 保持勾选，否则应用无法正常运行 |
| 2. 匿名使用统计 | 统计有多少人用了哪个功能（不记录你的具体内容） | 默认勾选 | 保持勾选，帮助我们知道哪些功能受欢迎 |
| 3. 性能指标 | 记录响应速度、内存占用等，用于优化 | 默认勾选 | 保持勾选，帮我们优化性能 |
| 4. 反馈内容记录 | 当你主动提交反馈时，记录反馈上下文 | 默认不勾选 | 建议勾选，方便我们更好地帮你解决问题 |

![数据采集同意弹窗](../assets/images/install-step3.png)

**操作**：

1. 阅读 4 个选项的说明
2. 根据你的偏好勾选（建议全部勾选，特别是第 4 个，能让我们更好地帮你）
3. 点击"我同意，继续"按钮
4. 进入下一步

## §5 常见问题（FAQ）

这里收集了用户最常遇到的 15 个问题。如果你的问题不在这里，请联系 §6 的客服渠道。

### 安装类问题

#### Q1: Mac 提示"无法验证开发者"或"无法打开，因为来自身份不明的开发者"怎么办？

**原因**：Mac 系统的安全机制会拦截所有非 App Store 下载的应用。

**解决步骤**：

1. **不要双击打开**，而是用"右键"（或两指点击触控板）点击 OPC-Agents 图标
2. 在弹出的菜单中选择"打开"
3. 这时弹出的对话框会多一个"仍要打开"按钮，点击它
4. 输入你的 Mac 登录密码确认
5. 应用就会正常打开，以后再双击也不会再拦截了

**如果上述方法不行**：

1. 打开"系统设置" → "隐私与安全性"
2. 滚动到页面底部，会看到"已阻止使用 OPC-Agents"的提示
3. 点击"仍要打开"按钮
4. 输入密码确认

#### Q2: Windows 杀毒软件报警（如 360、火绒、Windows Defender）怎么办？

**原因**：OPC-Agents 是开源软件，但杀毒软件可能误报。我们的代码完全开源在 https://github.com/lulin70/OPC-Agents ，欢迎审查。

**解决步骤**：

1. 在杀毒软件的弹窗中，选择"允许"或"信任"或"添加白名单"
2. 如果杀毒软件已经把文件删除或隔离：
   - 打开杀毒软件的"隔离区"或"恢复区"
   - 找到 OPC-Agents 相关文件，选择"恢复"并"添加信任"
3. 重新运行安装包

**如果 360 安全卫士顽固拦截**：

1. 打开 360 安全卫士
2. 点击"信任与阻止"
3. 在"阻止列表"中找到 OPC-Agents，点击"移除阻止"
4. 在"信任列表"中点击"添加信任"，把 OPC-Agents 安装目录加进去

#### Q3: 安装到一半失败怎么办？

**可能原因**：磁盘空间不足、网络中断、权限问题、安装包损坏。

**解决步骤**：

1. **检查磁盘空间**：确保 C 盘（Mac 是启动盘）有 5 GB 以上可用空间
2. **清理临时文件**：
   - Mac：打开"访达" → "前往"菜单 → 按住 Option 键 → "资源库" → "Caches"文件夹，清空里面的内容
   - Windows：按 Win+R 输入 `%temp%` 回车，全选删除
3. **以管理员身份运行**（仅 Windows）：
   - 右键点击安装包
   - 选择"以管理员身份运行"
4. **重新下载安装包**：可能安装包下载时损坏了，删掉重新下载
5. **重启电脑后再试**：有时候简单的重启就能解决权限问题

#### Q4: 提示"Python 未找到"怎么办？

**原因**：要么没装 Python，要么装了但没勾选"Add Python to PATH"。

**解决步骤**：

1. **先确认是否装了 Python**：
   - Mac：打开"终端"应用，输入 `python3 --version` 回车
   - Windows：按 Win+R 输入 `cmd` 回车，输入 `python --version` 回车
2. **如果提示"command not found"或"不是内部或外部命令"**：说明没装 Python，请按 §2.2.1 重新安装
3. **如果显示了 Python 版本但 OPC-Agents 还是找不到**：说明没加到 PATH

**修复 PATH（Windows）**：

1. 按 Win+R 输入 `sysdm.cpl` 回车
2. 点击"高级"标签 → "环境变量"
3. 在"系统变量"中找到 `Path`，双击它
4. 点击"新建"，添加 Python 安装路径（如 `C:\Users\你的用户名\AppData\Local\Programs\Python\Python310\`）
5. 再点"新建"，添加 `C:\Users\你的用户名\AppData\Local\Programs\Python\Python310\Scripts\`
6. 一路点"确定"保存
7. **重启电脑**让设置生效

**修复 PATH（Mac）**：

1. 打开"终端"
2. 输入以下命令查看 Python 路径：`which python3`
3. 如果显示路径（如 `/usr/local/bin/python3`），说明 Python 装好了但 PATH 没生效
4. 输入：`echo 'export PATH="/usr/local/bin:$PATH"' >> ~/.zshrc`
5. 输入：`source ~/.zshrc`
6. 重新启动 OPC-Agents

#### Q5: 提示"端口 8000 被占用"或"Port 8000 already in use"怎么办？

**原因**：你的电脑上有另一个程序正在使用 8000 端口（可能是另一个 OPC-Agents 实例没关，或其他软件占用了）。

**解决步骤（最简单的方法）**：

1. **重启电脑**：80% 的情况下重启就能解决
2. 重启后立即双击 OPC-Agents 图标启动

**如果重启不行**：

1. **Mac**：
   - 打开"终端"
   - 输入 `lsof -i :8000` 回车
   - 看输出最后一列的 PID 数字
   - 输入 `kill -9 那个数字` 回车
2. **Windows**：
   - 按 Win+R 输入 `cmd` 回车
   - 输入 `netstat -ano | findstr :8000` 回车
   - 看最后面的数字（PID）
   - 输入 `taskkill /PID 那个数字 /F` 回车

**终极方法**：在 OPC-Agents 安装目录找到配置文件 `config.toml` 或 `.env`，把 `PORT=8000` 改成 `PORT=8080`，保存后重启应用。

#### Q7: Ollama 模型下载太慢怎么办？

**原因**：Ollama 默认从国外服务器下载模型，国内访问慢。

**解决步骤**：

1. **切换到国内镜像**（推荐）：
   - 打开"终端"（Mac）或"命令提示符"（Windows）
   - Mac 输入：`echo 'export OLLAMA_HOST=https://mirrors.tuna.tsinghua.edu.cn/ollama' >> ~/.zshrc && source ~/.zshrc`
   - Windows：在"环境变量"里新建 `OLLAMA_HOST`，值为 `https://mirrors.tuna.tsinghua.edu.cn/ollama`
2. **换个更小的模型**：默认下载的模型较大（4-7 GB），可以换成小一点的：
   - 在 OPC-Agents 设置里把模型改成 `qwen2.5:3b` 或 `llama3.2:3b`（约 2 GB）
3. **晚上挂着下载**：睡前开始下载，第二天早上就好了
4. **直接换方案**：如果实在太慢，建议改用 MOKA 或 GLM 云端方案，不用下载模型

#### Q8: 测试连接失败怎么办？

**按以下顺序排查**：

1. **检查 API Key 是否正确**：
   - 复制时有没有多空格、少字符、少换行
   - 重新去原网站复制一遍
2. **检查网络**：
   - 打开浏览器访问任意网站（如 https://github.com ）看能不能正常打开
   - 如果在公司网络，可能被防火墙拦截了，联系 IT 放行 `api.moka-ai.com` 或 `open.bigmodel.cn`
3. **检查 API Key 是否还有效**：
   - 登录原网站看 API Key 状态是否"已激活"
   - 看是否有余额（MOKA 和 OpenAI 是付费的，余额用完会失败）
4. **重启应用**：完全退出 OPC-Agents（Mac：Command+Q；Windows：任务管理器结束进程），重新打开
5. **重启电脑**：终极方案，解决 90% 的奇怪问题

**如果以上都不行**：

- 在 [GitHub Issues](https://github.com/lulin70/OPC-Agents/issues) 提交问题，标题写"测试连接失败"，正文附上截图（API Key 部分打码）

#### Q9: 可以同时配置多个 AI 后端吗？

**可以**。OPC-Agents 支持同时配置多个 AI 后端，按优先级使用。

**配置方法**：

1. 进入"设置 → LLM 配置"
2. 在"已配置的后端"列表中，点击"添加后端"
3. 选择第二个 AI 后端（如已配 MOKA，再添加 Ollama）
4. 完成配置和测试连接
5. 在"优先级"列设置顺序（数字越小优先级越高）

**使用逻辑**：

- 优先级最高的后端先使用
- 如果失败（如网络问题、API Key 失效），自动降级到下一个
- 全部失败时降级到"模板模式"（功能受限但能用）

**典型组合**：

- MOKA（主力）+ Ollama（断网备用）
- GLM（免费额度）+ MOKA（额度用完切换）

#### Q10: 如何切换 AI 后端？

**临时切换**（只对当前任务）：

1. 在主界面对话框下方，点击"AI 模型"下拉框
2. 选择你想用的后端和模型
3. 这个对话开始就用新选择的模型

**永久切换**（修改默认）：

1. 进入"设置 → LLM 配置"
2. 在"默认后端"下拉框中选择
3. 点击"保存"
4. 所有新对话都用这个默认后端

**切换后旧的对话**：保持原来的后端不变（避免上下文丢失），新开的对话才用新后端。

### 使用类问题

#### Q11: 数据存在哪里？怎么备份？

**数据存储位置**：

- **Mac**：`/Users/你的用户名/.opc-agents/data/`
- **Windows**：`C:\Users\你的用户名\.opc-agents\data\`

里面包含：

- `conversations/`：所有对话历史
- `deliverables/`：生成的所有文档
- `finance/`：财务数据（收入、支出、报表）
- `crm/`：客户档案和跟进记录
- `tasks/`：任务列表
- `settings.json`：你的设置（不含 API Key，Key 单独加密存储）
- `memory/`：跨会话记忆（你的偏好、习惯）

**备份方法**：

1. **应用内备份（推荐）**：
   - 进入"设置 → 数据备份"
   - 点击"导出 ZIP 备份"
   - 选择保存位置（建议存到 U 盘或云盘）
   - 备份文件包含 SHA256 校验码，确保数据完整
2. **手动复制整个 data 文件夹**：
   - 关闭 OPC-Agents 应用
   - 复制上述路径的 data 文件夹到备份位置
3. **设置自动备份**（推荐）：
   - 进入"设置 → 数据备份 → 自动备份"
   - 勾选"每周自动备份"
   - 选择备份位置（U 盘或网盘同步文件夹）
   - 应用会在每周日凌晨 3 点自动备份

**恢复方法**：

1. 进入"设置 → 数据备份"
2. 点击"从备份恢复"
3. 选择之前导出的 ZIP 文件
4. 点击"恢复"，等待 30 秒
5. 应用会重启并加载备份数据

#### Q12: 可以在多台电脑使用吗？

**可以，但需要手动同步数据**。OPC-Agents 目前不提供云端同步（出于数据安全考虑）。

**多台电脑使用方案**：

1. **方案 A：每台电脑独立使用**（适合不同电脑处理不同事务）
   - 在每台电脑分别安装 OPC-Agents
   - 数据各自独立，互不影响
   - 适合：公司电脑处理公司事、家里电脑处理私事
2. **方案 B：用 U 盘同步数据**（适合需要在两台电脑间切换）
   - 在两台电脑都装 OPC-Agents
   - 每次换电脑前，在"设置 → 数据备份"导出 ZIP 到 U 盘
   - 在另一台电脑"从备份恢复"
3. **方案 C：专业版多设备**（适合重度用户）
   - 专业版许可证支持 2 台设备同时激活
   - 但数据仍需手动同步（同方案 B）

**未来计划**：我们正在开发"端到端加密的局域网同步"功能，预计 v0.6.0 发布，届时同一路由器下的多台电脑可以自动同步。

#### Q13: 卸载后数据会保留吗？

**会保留**。卸载 OPC-Agents 只会删除程序文件，不会删除数据。

**卸载方法**：

- **Mac**：把"应用程序"文件夹里的 OPC-Agents 拖到废纸篓，清空废纸篓
- **Windows**：在"设置 → 应用"里找到 OPC-Agents，点击"卸载"

**卸载后数据位置**（仍保留）：

- Mac：`/Users/你的用户名/.opc-agents/`
- Windows：`C:\Users\你的用户名\.opc-agents\`

**彻底删除数据**（如果想完全清除）：

1. 先备份（万一以后想用）
2. 关闭 OPC-Agents
3. 手动删除上述 `.opc-agents` 文件夹
4. 进入"设置 → 应用"卸载 OPC-Agents（如果还没卸载）
5. 数据彻底清除，无法恢复

> **重要提醒**（灰粉色 #C9A9A6）：
> 删除 `.opc-agents` 文件夹是不可逆操作。删除前请三思，建议先做一次 ZIP 备份存到 U 盘。

#### Q14: 中文界面可以切换英文或日文吗？

**可以，支持三种语言实时切换**。

**切换方法**：

1. 进入"设置 → 个人资料"
2. 找到"界面语言"下拉框
3. 选择：
   - 中文（简体）— 默认
   - English (US)
   - 日本語
4. 点击"保存"
5. 界面立即切换，**无需重启应用**

**覆盖范围**：

- 所有界面文本（按钮、菜单、提示）
- 所有错误消息
- 所有技能描述
- 所有引导教程

**不影响的部分**：

- 你和 AI 的对话内容（你想用中文就用中文，想用英文就用英文）
- 生成的文档内容（按你的指令语言生成）
- 数据存储格式（始终是 UTF-8 编码）
