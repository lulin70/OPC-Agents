## 📦 快速安装（5分钟）

### 方式一：pip 安装（最简单）

```bash
pip install opc-agents
opc-agents
```

> 首次使用需配置 API Key：在工作目录创建 `.env` 文件，填入 `MOKA_API_KEY=your-key`

### 方式二：源码安装（可定制）

#### 1. 克隆项目

```bash
git clone https://github.com/lulin70/OPC-Agents.git
cd OPC-Agents
```

#### 2. 安装依赖

**方式一：一键安装（推荐）**
```bash
chmod +x install.sh start.sh
./install.sh
```

**方式二：手动安装**
```bash
# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

#### 3. 配置API Key（可选但推荐）

```bash
# 复制配置模板
cp .env.example .env

# 编辑.env文件，填入你的API Key
# 支持以下任一配置：
# - MOKA_API_KEY（推荐，多模型支持）
# - GLM_API_KEY（智谱AI）
# - OPENAI_API_KEY（OpenAI）
# - OLLAMA_BASE_URL（Ollama本地模型，如 http://localhost:11434）
# - OLLAMA_ENABLED=true（启用Ollama，无需设置BASE_URL则使用默认地址）
# - OLLAMA_MODEL=llama3（Ollama模型名称，默认llama3）
```

**没有API Key？** 没关系！系统会自动降级到模板模式，仍然可以使用。

#### 4. 启动系统

```bash
./start.sh
```

浏览器会自动打开 `http://localhost:8501`

## 🚀 开始使用

### 典型使用场景

#### 场景1：信息收集
```
输入: "帮我收集2026年AI Agent最新趋势"
输出: 真实搜索结果 + 结构化研究报告（可下载.md文件）
```

#### 场景2：方案生成
```
输入: "帮我制定Q2营销方案"
输出: 完整执行计划，含目标/时间表/资源/风险/验收标准
```

#### 场景3：数据分析
```
输入: "分析一下我的业务现状"
输出: SWOT分析 + 具体行动清单
```

#### 场景4：自定义技能
```
1. 点击侧边栏"🔧 技能编辑器"
2. 填写技能名称、描述、分类
3. 设置输出格式和模板
4. 创建后即可在对话中使用
```

#### 场景5：质量/快速模式切换
```
侧边栏"执行模式"开关：
- 质量模式：三贤者完整闭环（策略→执行→反思→修正）
- 快速模式：跳过反思，直接执行返回
```

## ⚠️ Beta版已知限制

### 当前版本的限制

1. **搜索功能**
   - 依赖DuckDuckGo，可能偶尔失效
   - 失效时自动使用知识库兜底
   - 不影响基本使用

2. **LLM功能**
   - 需要配置API Key才能使用AI增强
   - 未配置时使用模板模式（质量略低但可用）

3. **内容质量**
   - 生成的内容需要人工review
   - 建议作为初稿使用，再根据实际调整

### 启动时的提示信息

启动时可能看到以下提示，**属于正常现象**：

- 检测到API Key → 显示"🤖 AI增强模式"
- 未检测到API Key → 显示"📝 模板模式"（功能正常，内容质量略低）

## 🐛 遇到问题？

### 常见问题

#### Q1: 启动失败，提示缺少依赖
```bash
# 解决方案：重新安装依赖
pip install --upgrade -r requirements.txt
```

#### Q2: 搜索功能不工作
```
原因: 网络问题或DuckDuckGo限流
影响: 系统会自动使用知识库兜底
建议: 稍后重试，或检查网络连接
```

#### Q3: LLM初始化失败
```
原因: 未配置API Key
影响: 使用模板模式（质量略低）
建议: 配置.env文件中的API Key
```

#### Q4: 生成的内容太通用
```
原因: 搜索失效 + LLM未配置
建议: 
1. 配置API Key启用AI增强
2. 提供更具体的输入信息
3. 在生成的基础上人工调整
```

## 💡 使用技巧

### 技巧1：提供具体信息

❌ 不好的输入：
```
"帮我写个方案"
```

✅ 好的输入：
```
"帮我制定Q2营销方案，产品是AI写作助手，
目标是月活从5000提升到10000，预算5万元"
```

### 技巧2：分步骤执行

对于复杂任务，建议拆分：

```
第1步: "帮我收集AI写作助手的竞品信息"
第2步: "基于以上信息，帮我制定差异化策略"
第3步: "帮我制定详细的执行计划"
```

### 技巧3：利用下载功能

每次生成的内容都可以下载为.md文件：
- 点击"📥 下载成果物"按钮
- 在本地编辑器中继续完善
- 版本管理更方便
