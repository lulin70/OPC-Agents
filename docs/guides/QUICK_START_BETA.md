## 📦 快速安装（5分钟）

### 方式一：pip 安装（最简单）

```bash
pip install opc-agents
opc-agents
```

> 首次使用需配置 API Key：在工作目录创建 `.env` 文件，填入 `MOKA_API_KEY=your-key`

### 方式二：源码安装（可定制）

#### 1. 克隆项目

```bash
git clone https://github.com/lulin70/OPC-Agents.git
cd OPC-Agents
```

#### 2. 安装依赖

**方式一：一键安装（推荐）**
```bash
chmod +x install.sh start.sh
./scripts/install.sh
```

**方式二：手动安装**
```bash
# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

#### 3. 配置API Key（可选但推荐）

```bash
# 复制配置模板
cp .env.example .env

# 编辑.env文件，填入你的API Key
# 支持以下任一配置：
# - MOKA_API_KEY（推荐，多模型支持）
# - GLM_API_KEY（智谱AI）
# - OPENAI_API_KEY（OpenAI）
# - OLLAMA_BASE_URL（Ollama本地模型，如 http://localhost:11434）
# - OLLAMA_ENABLED=true（启用Ollama，无需设置BASE_URL则使用默认地址）
# - OLLAMA_MODEL=llama3（Ollama模型名称，默认llama3）
```

**没有API Key？** 没关系！系统会自动降级到模板模式，仍然可以使用。

#### 4. 启动系统

```bash
./scripts/start.sh
```

浏览器会自动打开 `http://localhost:8501`

## 🚀 开始使用

### 典型使用场景

#### 场景1：信息收集
```
输入: "帮我收集2026年AI Agent最新趋势"
输出: 真实搜索结果 + 结构化研究报告（可下载.md文件）
```

#### 场景2：方案生成
```
输入: "帮我制定Q2营销方案"
输出: 完整执行计划，含目标/时间表/资源/风险/验收标准
```

#### 场景3：数据分析
```
输入: "分析一下我的业务现状"
输出: SWOT分析 + 具体行动清单
```

#### 场景4：自定义技能
```
1. 点击侧边栏"🔧 技能编辑器"
2. 填写技能名称、描述、分类
3. 设置输出格式和模板
4. 创建后即可在对话中使用
```

#### 场景5：质量/快速模式切换
```
侧边栏"执行模式"开关：
- 质量模式：三贤者完整闭环（策略→执行→反思→修正）
- 快速模式：跳过反思，直接执行返回
```

#### 场景6：统一设置管理（v0.2.0 新功能）
```
1. 点击侧边栏"⚙ 设置"或顶部导航栏设置图标
2. 5个标签页：
   - 🤖 LLM配置：管理多个API Key、模型选择、参数调优
   - 📧 SMTP邮件：配置邮件发送服务器、发件人信息
   - 🔑 API密钥：查看/管理所有已配置的API Key（加密存储）
   - 🛡 安全策略：数据加密、访问控制、审计日志设置
   - 👤 个人资料：业务类型、偏好设置、语言选择
3. 所有修改即时生效，无需重启
```

#### 场景7：首次运行引导
```
首次启动时自动触发3步向导：
Step 1: 🎉 欢迎页 — 了解OPC-Agents核心能力
Step 2: 🔑 API Key配置 — 快速配置LLM服务（支持跳过）
Step 3: ✨ 功能介绍 — 了解21个内置技能和主要功能
```

#### 场景8：数据备份与恢复
```
位置：设置页面 → 数据备份标签
支持的导出格式：
- ZIP压缩包（完整备份，含SHA256校验）
- JSON格式（数据交换）
- CSV格式（财务/CRM数据表格）

安全特性：
- Zip Slip路径遍历防护
- 敏感字段自动脱敏
- 备份文件加密存储
```

#### 场景9：国际化语言切换
```
支持3种语言实时切换（无需重启）：
- 🇨🇳 中文 (zh_CN) — 默认
- 🇺🇸 English (en_US)
- 🇯🇵 日本語 (ja_JP)

切换方式：设置页面 → 个人资料 → 语言选择
覆盖范围：全部UI文本 + 错误消息 + 技能描述
```

#### 场景10：Apple Shortcuts 快捷操作
```
通过CLI调用5个预定义快捷动作：

# 快速创建任务
opc-agents --shortcut quick_task --goal "完成Q2报告"

# 查询任务状态
opc-agents --shortcut query_status

# 创建交付物
opc-agents --shortcut create_deliverable --type report

# 记录收入
opc-agents --shortcut record_income --amount 5000 --source "咨询费"

# 生成日报
opc-agents --shortcut daily_report
```

## ⚠ Beta版已知限制

### 当前版本的限制

1. **搜索功能**
   - 依赖DuckDuckGo，可能偶尔失效
   - 失效时自动使用知识库兜底
   - 不影响基本使用

2. **LLM功能**
   - 需要配置API Key才能使用AI增强
   - 未配置时使用模板模式（质量略低但可用）

3. **内容质量**
   - 生成的内容需要人工review
   - 建议作为初稿使用，再根据实际调整

### 启动时的提示信息

启动时可能看到以下提示，**属于正常现象**：

- 检测到API Key → 显示"🤖 AI增强模式"
- 未检测到API Key → 显示"📝 模板模式"（功能正常，内容质量略低）

## 🐛 遇到问题？

### 常见问题

#### Q1: 启动失败，提示缺少依赖
```bash
# 解决方案：重新安装依赖
pip install --upgrade -r requirements.txt
```

#### Q2: 搜索功能不工作
```
原因: 网络问题或DuckDuckGo限流
影响: 系统会自动使用知识库兜底
建议: 稍后重试，或检查网络连接
```

#### Q3: LLM初始化失败
```
原因: 未配置API Key
影响: 使用模板模式（质量略低）
建议: 配置.env文件中的API Key
```

#### Q4: 生成的内容太通用
```
原因: 搜索失效 + LLM未配置
建议: 
1. 配置API Key启用AI增强
2. 提供更具体的输入信息
3. 在生成的基础上人工调整
```

## 💡 使用技巧

### 技巧1：提供具体信息

❌ 不好的输入：
```
"帮我写个方案"
```

✅ 好的输入：
```
"帮我制定Q2营销方案，产品是AI写作助手，
```
