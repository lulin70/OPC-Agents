# OPC-Agents v0.3.0 用户试用安装指南

> **版本**: v0.3.0
> **更新日期**: 2026-06-19
> **适用对象**: 一人公司经营者（非技术背景）
> **预计耗时**: 3 分钟完成配置

## 📖 这是什么？

**OPC-Agents** 是一款帮你"说一句话就干活"的 AI 助手，专为一人公司设计。

它能帮你做这些事：
- 📧 **写邮件**：说"帮我给王总写跟进邮件"，自动生成专业草稿
- 💰 **记账**：说"记一笔收入 5000 元"，自动记录到账本
- 📊 **出报告**：说"生成本月经营报告"，自动汇总收支和趋势

**你不需要懂编程**，跟着下面的步骤操作就行。

## ✅ 前置条件（开始前请确认）

2. 在终端窗口输入下面这行命令，按回车：

[截图：终端输入 python3 --version 后的输出结果]

**Windows 用户**：
1. 按 `Win + R` 键，输入 `cmd`，回车打开命令提示符
2. 输入下面这行命令，按回车：
   ```
   python --version
   ```
3. **预期看到**：类似 `Python 3.10.8` 或更高版本的数字

[截图：Windows cmd 输入 python --version 后的输出结果]

## 🚀 5 步安装法

### 第 1 步：下载项目

有两种方式，**任选一种**即可。

#### 方式 A：下载 ZIP 压缩包（推荐非技术用户）

1. 用浏览器打开：https://github.com/lulin70/OPC-Agents
2. 点击页面绿色的 **`Code`** 按钮
3. 在弹出菜单中选择 **`Download ZIP`**

[截图：GitHub 项目页面，标注绿色 Code 按钮和 Download ZIP 选项的位置]

4. 下载完成后，**解压 ZIP 文件**到你想存放的位置（例如：桌面 或 `D:\我的工具`）
5. 解压后会得到一个名为 `OPC-Agents-main` 的文件夹

> 💡 **建议**：把文件夹重命名为 `OPC-Agents`，方便后续操作。

#### 方式 B：用 git 命令下载（适合略懂技术的用户）

打开终端，输入：
```bash
git clone https://github.com/lulin70/OPC-Agents.git
cd OPC-Agents
```

**预期看到**：终端显示下载进度，最后出现 `OPC-Agents` 文件夹。

---

### 第 2 步：安装依赖

进入 `OPC-Agents` 文件夹后，运行一键安装脚本。

#### Mac / Linux 用户

1. 打开终端，**用 cd 命令进入项目文件夹**：
   ```bash
   cd /你/解压/的/路径/OPC-Agents
   ```
   > 💡 小技巧：在终端输入 `cd ` 后，把文件夹拖到终端窗口里，路径会自动填入。

2. 给脚本加上"可执行"权限（只需第一次做）：
   ```bash
   chmod +x install.sh start.sh
   ```

3. 运行安装脚本：
   ```bash
   ./scripts/install.sh
   ```

[截图：终端运行 ./scripts/install.sh 的过程，显示检查 Python、创建虚拟环境、安装依赖的输出]

**预期看到**（按顺序）：
- ✅ `Python 版本符合要求`
- ✅ `虚拟环境创建成功`
- ✅ `依赖包安装完成`（这一步可能需要 2-5 分钟，请耐心等待）
- ✅ `配置文件 .env 创建成功`
- ✅ `安装完成！`

#### Windows 用户

> ⚠️ **重要提示**：OPC-Agents 当前版本主要面向 Mac 用户，Windows 支持需要通过 WSL（Windows Subsystem for Linux）或 Git Bash 运行 `.sh` 脚本。

1. 安装 [WSL](https://learn.microsoft.com/zh-cn/windows/wsl/install) 或 [Git Bash](https://git-scm.com/downloads)
2. 进入 `OPC-Agents` 文件夹
3. 在 WSL/Git Bash 终端中运行：
   ```bash
   chmod +x install.sh
   ./scripts/install.sh
   ```

**预期看到**：终端显示安装进度（虚拟环境创建→依赖安装→配置文件创建），最后显示"安装完成"。

> ⚠️ **如果安装失败**：请看本文档末尾的 FAQ 第 1 条。

### 第 3 步：配置 API Key（重要！）

#### 什么是 API Key？

**API Key** 就像是 AI 大脑的"通行证"。OPC-Agents 本身不带 AI 大脑，需要连接一个外部的大模型服务（类似 ChatGPT 那种）才能理解你说的话。

**没有 API Key 也能用**（详见下方"无 API Key 体验模式"），但功能会受限，建议配置一个。

#### 如何免费获取 MokaAI 密钥（推荐）

我们推荐使用 **MokaAI**，它提供 Claude Sonnet 4 模型，中文效果好。

1. 用浏览器打开：https://moka-ai.com
2. 点击右上角 **注册/登录**
3. 完成注册（需邮箱验证）
4. 登录后进入 **控制台** → **API Keys** 页面
5. 点击 **创建新密钥**，复制生成的密钥（形如 `sk-xxxxxxxxxxxx`）

[截图：MokaAI 官网注册页面]
[截图：MokaAI 控制台 API Keys 页面，标注"创建新密钥"按钮位置]
[截图：密钥生成后复制按钮的位置]

> 💡 **免费额度**：MokaAI 新用户有免费体验额度，足够试用 1 周。
>
> **其他选择**：你也可以用智谱 GLM-4（https://open.bigmodel.cn ，国产大模型，有免费额度）或 OpenAI（https://platform.openai.com ，付费）。

#### 如何填写 API Key？

1. 在 `OPC-Agents` 文件夹中找到 `.env` 文件
   - **Mac 用户**：可以用"文本编辑"打开，或终端输入 `open -e .env`
   - **Windows 用户**：用"记事本"打开（如果看不到文件，请在文件夹选项中开启"显示隐藏文件"）

2. 找到这一行（大约在第 29 行）：
   ```
   # MOKA_API_KEY=your-moka-api-key-here
   ```

3. **去掉行首的 `#` 号**，并把 `your-moka-api-key-here` 替换成你刚复制的密钥：
   ```
   MOKA_API_KEY=sk-你刚才复制的密钥
   ```

[截图：.env 文件编辑前后对比，标注 # 号删除位置和密钥替换位置]

4. 保存文件（Mac: `Command + S`；Windows: `Ctrl + S`）

**预期看到**：`.env` 文件中有一行 `MOKA_API_KEY=sk-...`，且行首没有 `#`。

> ⚠️ **重要**：密钥前后不要加引号或空格，等号两边也不要有空格。

如果没有 API Key，也能体验大部分功能，系统会自动进入 **模板模式**。

| 功能 | 模板模式 | AI 模式（有 API Key） |
|------|---------|---------------------|
| 记账 | ✅ 完全可用 | ✅ 完全可用 |
| 报告生成 | ✅ 可用（基于模板） | ✅ 可用（更智能） |

> 💡 **建议**：先用模板模式体验记账和报告功能，觉得有用后再去注册 API Key 解锁完整能力。

## ❓ 常见问题 FAQ

### Q1: 安装失败怎么办？

**可能原因与解决**：

1. **Python 版本过低**
   - 现象：提示"需要 Python 3.10 或更高版本"
   - 解决：到 https://www.python.org/downloads/ 下载最新版

2. **pip 安装依赖报错**
   - 现象：红色错误文字，提示网络或权限问题
   - 解决 1（网络问题）：使用国内镜像源
     ```bash
     pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
     ```
   - 解决 2（权限问题，Mac/Linux）：加 `--user`
     ```bash
     pip install --user -r requirements.txt
     ```

3. **Windows 找不到 python 命令**
   - 解决：重装 Python 时勾选 `Add Python to PATH`，或手动添加安装路径到系统环境变量

---

### Q2: 启动报错怎么办？

**常见报错与解决**：

1. **`Port 8501 is already in use`**（端口被占用）
   - 解决：应用其实已启动，直接浏览器访问 `http://localhost:8501` 即可
   - 或关闭其他占用 8501 端口的程序后重试

2. **`ModuleNotFoundError: No module named 'xxx'`**（缺少模块）
   - 解决：依赖没装全，重新运行安装脚本，或手动执行：
     ```bash
     pip install -r requirements.txt
     ```

3. **浏览器打不开页面**
   - 解决：手动在浏览器地址栏输入 `http://localhost:8501`

4. **启动后白屏**
   - 解决：等待 10-30 秒让应用初始化；若仍白屏，按 `Ctrl+C` 停止后重新运行 `./scripts/start.sh`

### Q5: 数据存在哪里？

**所有数据都存在你电脑本地**，不会上传到任何服务器：

- **数据目录**：`OPC-Agents/data/` 文件夹
- **数据库文件**：`data/opc.db`（SQLite 数据库，记账/客户/任务等数据）
- **报告文件**：`data/reports/`（生成的 Markdown 报告）
- **配置文件**：`.env`（API Key 等配置，加密存储）
- **加密密钥**：`.env.local`（自动生成，请勿删除，否则加密数据无法恢复）

> 🔒 **隐私保护**：你的所有数据（记账、邮件、客户信息）都只存在你本地电脑，我们无法访问。

### Q7: 如何更新版本？

**方式 A：如果是 git clone 下载的**

```bash
cd OPC-Agents
git pull origin main
./scripts/install.sh   # 重新安装依赖（如有更新）
```
