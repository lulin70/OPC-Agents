## 七、用户使用指南

### 7.1 绑定流程（Web 界面）

1. **访问配对页面**
   ```
   http://localhost:5009/wechat/pairing
   ```

2. **查看二维码**
   - 页面显示 8 位配对码
   - 显示二维码图片
   - 显示倒计时（1 小时）

3. **微信扫码绑定**
   - 打开微信"扫一扫"
   - 扫描二维码
   - 点击"确认绑定"

4. **等待绑定成功**
   - 页面自动检测绑定状态
   - 显示"绑定成功"
   - 自动跳转到对话页面

5. **开始使用**
   - 在微信中发送消息
   - OPC-Agents 自动回复
   - 支持文本、图片、文件

### 7.2 绑定流程（CLI）

```bash
# 1. 列出待处理配对
openclaw pairing list wechat

# 2. 批准配对
openclaw pairing approve wechat ABCD1234

# 3. 验证绑定
openclaw pairing list-approved wechat
```

### 7.3 故障排查

#### 问题 1: 二维码无法扫描
- **原因**: 网络问题或二维码过期
- **解决**: 刷新页面重新生成

#### 问题 2: 绑定后无法通信
- **原因**: 设备未批准或配置错误
- **解决**: 检查配对状态，确认已批准

#### 问题 3: 配对码已过期
- **原因**: 超过 1 小时未批准
- **解决**: 重新生成配对码

## 八、安全机制

### 8.1 配对安全

| 机制 | 说明 | 效果 |
|------|------|------|
| 8 位配对码 | 大写，排除歧义字符 | 防止暴力破解 |
| 1 小时过期 | 自动清理过期请求 | 防止长期未使用 |
| 待处理上限 | 每个频道最多 3 个 | 防止洪水攻击 |
| 设备批准列表 | 只有批准的设备可连接 | 白名单机制 |
| 可选 Token 认证 | 额外认证层 | 双重保护 |

### 8.2 通信安全

| 机制 | 说明 | 效果 |
|------|------|------|
| WebSocket 加密 | 支持 WSS | 防止窃听 |
| 设备身份验证 | 连接时验证设备 ID | 防止冒充 |
| 消息签名 | 可选消息签名 | 防止篡改 |
| IP 白名单 | 限制访问 IP | 网络隔离 |

### 8.3 最佳实践

1. **定期审查**: 每月检查已批准设备列表
2. **及时撤销**: 发现可疑设备立即撤销
3. **网络隔离**: 建议在内网环境使用
4. **日志审计**: 开启详细日志记录
