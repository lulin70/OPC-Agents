# OPC-Agents 部署指南

## 1. 部署环境准备

### 1.1 系统要求

- **操作系统**：
  - Windows 10/11
  - macOS 10.15+
  - Linux (Ubuntu 18.04+, CentOS 7+)

- **硬件要求**：
  - CPU：至少2核
  - 内存：至少4GB
  - 磁盘空间：至少10GB

- **软件要求**：
  - Python 3.7+
  - pip 20.0+
  - Git

### 1.2 依赖安装

#### 1.2.1 Python 安装

- **Windows**：
  1. 访问 [Python官网](https://www.python.org/downloads/)
  2. 下载最新版本的Python
  3. 运行安装程序，勾选"Add Python to PATH"
  4. 完成安装

- **macOS**：
  1. 使用Homebrew：`brew install python`
  2. 或从官网下载安装包

- **Linux**：
  1. Ubuntu/Debian：`sudo apt install python3 python3-pip`
  2. CentOS/RHEL：`sudo yum install python3 python3-pip`

#### 1.2.2 Git 安装

- **Windows**：访问 [Git官网](https://git-scm.com/downloads) 下载安装
- **macOS**：`brew install git`
- **Linux**：
  - Ubuntu/Debian：`sudo apt install git`
  - CentOS/RHEL：`sudo yum install git`

## 2. 系统部署

### 2.1 克隆代码库

```bash
git clone https://github.com/yourusername/OPC-Agents.git
cd OPC-Agents
```

### 2.2 安装依赖

```bash
# 创建虚拟环境（可选）
python3 -m venv venv

# 激活虚拟环境
# Windows: venv\Scripts\activate
# macOS/Linux: source venv/bin/activate

# 安装依赖
pip3 install -r requirements.txt
```

### 2.3 配置环境变量

#### 2.3.1 必要环境变量

- **OPC_AGENTS_DIR**：系统工作目录
- **API_KEY**：API认证密钥（可选）

#### 2.3.2 设置方法

- **Windows**：
  ```cmd
  set OPC_AGENTS_DIR=C:\path\to\opc_agents
  set API_KEY=your_api_key
  ```

- **macOS/Linux**：
  ```bash
  export OPC_AGENTS_DIR=/path/to/opc_agents
  export API_KEY=your_api_key
  ```

- **永久设置**：
  - Windows：在系统环境变量中添加
  - macOS/Linux：在 `~/.bashrc` 或 `~/.zshrc` 中添加

### 2.4 配置文件

#### 2.4.1 系统配置

编辑 `config/system.json`：

```json
{
  "web_port": 5000,
  "log_level": "info",
  "max_agents": 10,
  "api_key": "your_api_key"
}
```

#### 2.4.2 模型配置

编辑 `config/models.json`：

```json
{
  "openai": {
    "api_key": "your_openai_api_key",
    "model": "gpt-4"
  },
  "anthropic": {
    "api_key": "your_anthropic_api_key",
    "model": "claude-3"
  }
}
```

### 2.5 启动系统

#### 2.5.1 开发环境

```bash
python3 main.py
```

#### 2.5.2 生产环境

使用 Gunicorn 作为WSGI服务器：

```bash
# 安装Gunicorn
pip3 install gunicorn

# 启动服务
gunicorn -w 4 -b 0.0.0.0:5000 main:app
```

#### 2.5.3 后台运行

- **Linux/macOS**：
  ```bash
  nohup python3 main.py > app.log 2>&1 &
  ```

- **Windows**：
  使用服务管理器或后台运行工具

### 2.6 验证部署

1. 访问 `http://localhost:5000` 检查Web界面
2. 访问 `http://localhost:5000/api/system/status` 检查API状态
3. 运行命令 `python3 cli/cli.py system info` 检查系统信息

## 3. 容器化部署

### 3.1 Docker 部署

#### 3.1.1 创建 Dockerfile

```Dockerfile
FROM python:3.9-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

ENV OPC_AGENTS_DIR=/app
ENV API_KEY=your_api_key

EXPOSE 5000

CMD ["python", "main.py"]
```

#### 3.1.2 构建镜像

```bash
docker build -t opc-agents .
```

#### 3.1.3 运行容器

```bash
docker run -d -p 5000:5000 --name opc-agents opc-agents
```

### 3.2 Docker Compose 部署

创建 `docker-compose.yml`：

```yaml
version: '3'
services:
  opc-agents:
    build: .
    ports:
      - "5000:5000"
    environment:
      - OPC_AGENTS_DIR=/app
      - API_KEY=your_api_key
    volumes:
      - ./config:/app/config
      - ./logs:/app/logs
```

启动服务：

```bash
docker-compose up -d
```

## 4. 反向代理配置

### 4.1 Nginx 配置

```nginx
server {
    listen 80;
    server_name example.com;

    location / {
        proxy_pass http://localhost:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 静态文件
    location /static {
        alias /path/to/opc-agents/static;
        expires 30d;
    }
}
```

### 4.2 Apache 配置

```apache
<VirtualHost *:80>
    ServerName example.com

    ProxyPass / http://localhost:5000/
    ProxyPassReverse / http://localhost:5000/

    # 静态文件
    Alias /static /path/to/opc-agents/static
    <Directory /path/to/opc-agents/static>
        Require all granted
    </Directory>
</VirtualHost>
```

## 5. 自动化部署

### 5.1 CI/CD 配置

#### 5.1.1 GitHub Actions

创建 `.github/workflows/deploy.yml`：

```yaml
name: Deploy OPC-Agents

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.9'
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
    - name: Run tests
      run: python -m pytest tests/
    - name: Deploy to server
      uses: appleboy/ssh-action@master
      with:
        host: ${{ secrets.SERVER_HOST }}
        username: ${{ secrets.SERVER_USER }}
        key: ${{ secrets.SERVER_KEY }}
        script: |
          cd /path/to/opc-agents
          git pull
          pip install -r requirements.txt
          systemctl restart opc-agents
```

### 5.2 系统服务配置

#### 5.2.1 Systemd 服务

创建 `/etc/systemd/system/opc-agents.service`：

```ini
[Unit]
Description=OPC-Agents Service
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/path/to/opc-agents
Environment="OPC_AGENTS_DIR=/path/to/opc-agents"
Environment="API_KEY=your_api_key"
ExecStart=/path/to/venv/bin/python main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

启动服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable opc-agents
sudo systemctl start opc-agents
```

## 6. 监控与维护

### 6.1 日志管理

- **系统日志**：`logs/system.log`
- **API日志**：`logs/api.log`
- **代理日志**：`logs/agent.log`

### 6.2 监控工具

- **Prometheus**：监控系统指标
- **Grafana**：可视化监控数据
- **ELK Stack**：日志分析

### 6.3 定期维护

1. **更新依赖**：
   ```bash
   pip install --upgrade -r requirements.txt
   ```

2. **备份配置**：
   ```bash
   cp -r config/ config_backup/
   ```

3. **清理日志**：
   ```bash
   find logs/ -name "*.log" -size +10M -delete
   ```

## 7. 扩展与定制

### 7.1 添加新模型

1. 在 `model_integration/model_adapters.py` 中添加新模型适配器
2. 在 `config/models.json` 中配置模型参数
3. 重启系统

### 7.2 添加新技能

1. 创建技能文件
2. 使用命令行注册技能：
   ```bash
   python3 cli/cli.py skill register new_skill /path/to/skill
   ```

### 7.3 自定义Web界面

1. 修改 `templates/` 目录下的HTML模板
2. 修改 `static/` 目录下的CSS和JavaScript文件
3. 重启系统
