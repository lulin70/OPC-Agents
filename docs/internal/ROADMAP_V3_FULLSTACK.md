## 五、风险与约束

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| SMTP配置复杂 | 用户可能不会配邮箱 | 提供主流邮箱(QQ/163/Gmail)一键配置向导 |
| SQLite并发限制 | 多任务同时写入可能冲突 | 使用WAL模式+写锁队列 |
| 数据安全 | 本地存储无加密 | 敏感字段AES加密+文件权限0600 |
| 技能膨胀 | 21个技能维护成本高 | 统一技能基类+插件化架构 |

## 六、外部技能扩展系统（Phase D 详细设计）

### 6.1 技能市场搜索（SkillMarketplace）

| 项目 | 规格 |
|------|------|
| 功能 | 搜索/浏览/安装社区开发的外部技能 |
| 搜索方式 | 关键词搜索、分类浏览、热门推荐 |
| 技能元数据 | 名称/描述/作者/版本/下载量/评分/信任等级 |
| 安装流程 | 搜索 → 预览 → 确认 → 沙箱安装 → 信任评级 |
| 存储 | `data/external_skills/` |

### 6.2 MCP服务发现

| 项目 | 规格 |
|------|------|
| 功能 | 发现/连接MCP（Model Context Protocol）服务器 |
| 发现方式 | 注册中心查询、URL直连、本地配置 |
| 连接协议 | HTTPS（强制）、WebSocket |
| 能力声明 | 服务器声明支持的tools/resources/prompts |
| 存储 | `data/mcp_connections.json` |

### 6.3 用户画像（UserProfile）

| 项目 | 规格 |
|------|------|
| 功能 | 记录用户偏好、使用习惯，驱动技能推荐 |
| 画像维度 | 业务类型/常用技能/使用频率/偏好标签 |
| 推荐策略 | 基于画像的协同过滤 + 内容匹配 |
| 隐私保护 | 画像数据本地存储，不上传 |
| 存储 | `data/user_profile.json` |

### 6.4 安全沙箱机制

| 项目 | 规格 |
|------|------|
| 隔离方式 | 进程级隔离，独立Python子进程 |
| 资源限制 | CPU时间/内存/磁盘/网络白名单 |
| 文件访问 | 仅允许访问沙箱工作目录 |
| 网络访问 | 白名单域名，默认禁止外联 |
| 超时控制 | 单次执行最长60秒 |
| 审计 | 所有外部技能操作记录审计日志 |

### 6.5 信任等级体系

| 等级 | 名称 | 权限 | 条件 |
|------|------|------|------|
| L0 | 不可信 | 禁止安装 | 无签名/被举报/已知漏洞 |
| L1 | 基础信任 | 只读+沙箱执行 | 社区注册+基础审核 |
| L2 | 标准信任 | 读写+网络白名单 | 10+好评+代码审查 |
| L3 | 高度信任 | 完整权限 | 官方认证+安全审计通过 |
