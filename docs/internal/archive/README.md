# Archive

This directory contains historical design documents, consensus records, and review reports from previous development cycles.

## Purpose

These files are preserved for historical reference. They document design decisions, architecture evolution, and lessons learned that shaped the current system.

## Structure

Files are organized by version:

- `v0.1.0` — Initial consensus and design records
- `v0.1.5` — Optimization consensus and decision records
- `v0.1.6` — Critical reviews, tech debt memos, and final assessment
- `v0.1.9` — Gamma consensus review and critical fixes
- `v0.2.0` — Sprint plan and complete analysis report
- `v3.x` — Architecture design, test plans, and roadmap evolution

## Note

Files in this archive are **not actively maintained**. For current architecture and design documentation, refer to `docs/architecture/` and `docs/internal/`.
