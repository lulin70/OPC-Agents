# OPC-Agents 系统用户手册

## 1. 系统概述

OPC-Agents（One Person Company Agents）是一个为个人公司设计的多代理系统，通过AI代理的协作来完成各种任务。系统包含多个部门的专业代理，每个代理都具备特定的技能和职责。

### 1.1 系统架构

- **核心模块**：代理优化器、技能管理器、MCP集成、安装管理器
- **模型集成**：支持多种AI模型，包括OpenAI、Anthropic、Google、Azure、GLM和本地模型
- **API层**：提供RESTful API接口，支持外部集成
- **Web界面**：提供直观的用户界面，方便用户管理和使用系统
- **命令行接口**：支持命令行操作，适合自动化和脚本执行

## 2. 安装指南

### 2.1 系统要求

- Python 3.7+
- pip 20.0+
- 操作系统：Windows、macOS、Linux

### 2.2 安装步骤

1. **克隆代码库**
   ```bash
   git clone https://github.com/yourusername/OPC-Agents.git
   cd OPC-Agents
   ```

2. **安装依赖**
   ```bash
   pip3 install -r requirements.txt
   ```

3. **配置环境变量**
   ```bash
   # Linux/macOS
   export OPC_AGENTS_DIR=/path/to/opc_agents
   
   # Windows
   set OPC_AGENTS_DIR=C:\path\to\opc_agents
   ```

4. **启动系统**
   ```bash
   python3 main.py
   ```

## 3. 系统使用

### 3.1 Web界面

1. **访问Web界面**
   打开浏览器，访问 `http://localhost:5007`

2. **部门管理**
   - 点击左侧导航栏的部门名称，查看部门详情
   - 查看部门下的代理列表
   - 为代理分配任务

3. **代理管理**
   - 点击左侧导航栏的"代理管理"链接
   - 查看所有代理列表
   - 创建新代理
   - 编辑现有代理
   - 删除代理

4. **技能市场**
   - 点击左侧导航栏的"技能市场"链接
   - 浏览可用技能列表
   - 查看技能详情和评分
   - 获取技能到系统
   - 发布自己的技能

5. **仪表板定制**
   - 点击左侧导航栏的"仪表板"链接
   - 点击"定制仪表板"按钮进入编辑模式
   - 从组件库中添加组件
   - 调整组件大小和位置
   - 保存定制配置

6. **通知系统**
   - 点击顶部导航栏的通知图标
   - 查看通知列表
   - 点击通知查看详情
   - 标记通知为已读
   - 点击"通知设置"调整通知偏好

7. **总裁办功能**
   - 点击左侧导航栏的"总裁办"链接
   - 使用任务分解工具分解复杂任务
   - 查看任务进度跟踪
   - 生成综合报告
   - 使用战略规划工具进行战略分析

8. **财务部功能**
   - 点击左侧导航栏的"财务部"链接
   - 查看Token使用预测
   - 分析模型使用成本
   - 设置Token使用预算
   - 查看预算使用情况

### 3.2 命令行接口

1. **查看帮助**
   ```bash
   python3 cli/cli.py --help
   ```

2. **常用命令**
   - **系统信息**：`python3 cli/cli.py system info`
   - **系统状态**：`python3 cli/cli.py system status`
   - **代理管理**：`python3 cli/cli.py agent list`
   - **模型管理**：`python3 cli/cli.py model list`
   - **技能管理**：`python3 cli/cli.py skill list`

### 3.3 API接口

1. **API文档**
   访问 `http://localhost:5000/api/docs` 查看API文档

2. **常用API**
   - **获取部门列表**：`GET /api/departments`
   - **获取代理列表**：`GET /api/agents`
   - **创建代理**：`POST /api/agents`
   - **更新代理**：`PUT /api/agents/{id}`
   - **删除代理**：`DELETE /api/agents/{id}`

## 4. 核心功能

### 4.1 代理优化

- **性能分析**：分析代理的性能指标
- **改进计划**：生成代理改进计划
- **自动优化**：自动优化代理性能
- **Agent绩效评估**：对代理进行绩效评估，生成详细的评估报告

### 4.2 技能管理

- **技能注册**：注册新技能
- **技能使用跟踪**：跟踪技能使用情况
- **技能推荐**：基于使用情况生成技能推荐
- **技能市场**：发布和获取技能，评价技能质量

### 4.3 MCP集成

- **技能获取**：从MCP获取可信赖的技能
- **技能验证**：验证技能的安全性和可靠性
- **技能更新**：更新现有技能
- **MCP自动同步**：定期从MCP自动更新技能库

### 4.4 模型管理

- **模型注册**：注册不同的AI模型
- **模型切换**：在不同模型之间切换
- **模型评估**：评估模型性能
- **模型自动切换**：基于任务类型和性能自动选择最佳模型

### 4.5 总裁办功能

- **任务分解**：将复杂任务分解为更小的子任务
- **进度跟踪**：实时跟踪任务和项目进度
- **报告生成**：生成综合报告，提供智能洞察
- **战略规划**：使用三贤者决策系统进行战略分析
- **资源优化**：分析和优化资源分配

### 4.6 财务部功能

- **Token使用监控**：监控Token使用情况
- **Token使用预测**：基于历史数据预测未来Token使用
- **成本分析**：分析不同模型的使用成本
- **预算管理**：设置和管理Token使用预算

### 4.7 系统可靠性

- **任务失败自动重试**：自动重试失败的任务
- **模型故障转移**：当一个模型不可用时自动切换到备用模型
- **数据备份**：定期备份系统数据和配置

### 4.8 用户体验

- **响应式设计**：适配不同设备尺寸
- **仪表板定制**：定制个人仪表板
- **通知系统**：实时通知任务状态和系统事件
- **一键任务分配**：简化任务分配流程
- **进度可视化**：直观展示任务和项目进度

## 5. 故障排除

### 5.1 常见问题

1. **Web界面无法访问**
   - 检查服务是否正在运行
   - 检查端口是否被占用
   - 检查防火墙设置

2. **代理性能不佳**
   - 使用命令行工具分析代理性能
   - 生成改进计划并执行优化
   - 考虑使用更强大的AI模型

3. **技能注册失败**
   - 检查技能路径是否正确
   - 检查技能文件格式是否正确
   - 检查MCP连接是否正常

### 5.2 日志查看

- **系统日志**：`logs/system.log`
- **代理日志**：`logs/agent.log`
- **API日志**：`logs/api.log`

## 6. 高级配置

### 6.1 模型配置

在 `config/models.json` 文件中配置模型参数：

```json
{
  "openai": {
    "api_key": "your_api_key",
    "model": "gpt-4"
  },
  "anthropic": {
    "api_key": "your_api_key",
    "model": "claude-3"
  }
}
```

### 6.2 系统配置

在 `config/system.json` 文件中配置系统参数：

```json
{
  "web_port": 5000,
  "log_level": "info",
  "max_agents": 10
}
```
