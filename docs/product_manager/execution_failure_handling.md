### 当前系统的 4 层防护机制

系统已经设计了**完整的 4 层防护机制**来处理执行时的意外失败：

### 🔄 第 1 层：自动重试机制

**位置**: [`task_executor.py`](file:///Users/lin/Documents/trae_projects/OPC-Agents/opc_manager/task_executor.py#L267-L310)

**触发条件**: 任务执行失败

**处理逻辑**:
```python
current_retry = task_data.get("_retry_count", 0)
max_retry = task_data.get("_max_retry", 5)  # 默认 5 次

if current_retry < max_retry:
    # 自动重试（指数退避：2→4→8→16→32 秒）
    task_data["_retry_count"] = current_retry + 1
    time.sleep(2 * (2 ** current_retry))
    重新提交到队列
else:
    # 达到最大重试次数，进入第 2 层
```

**适用场景**:
- ✅ 临时性网络故障
- ✅ API 短暂不可用
- ✅ 资源暂时不足

### 🧠 第 2 层：智能错误分类

**位置**: [`error_handler.py`](file:///Users/lin/Documents/trae_projects/OPC-Agents/opc_manager/error_handler.py)

**触发条件**: 达到最大重试次数

**4 类错误处理**:

| 错误类型 | 示例 | 处理方式 | 用户干预 |
|---------|------|---------|---------|
| 🔴 可重试 - 自动 | 网络超时、API 限流 | 自动重试（≤3 次） | 否 |
| 🟡 可重试 - 建议 | 资源不足、依赖缺失 | 提供方案，用户确认 | 是 |
| 🟠 不可重试 | 代码 bug、权限不足 | 停止执行，报告用户 | 是 |
| ⚠️ 高风险 | 付费 API 失败、数据丢失 | 立即停止，等待指示 | 是 |

**智能分类示例**:
```python
# 网络超时 → 自动重试
"Connection timeout" → 自动重试 3 次

# 内存不足 → 建议重试
"MemoryError" → 建议："关闭其他应用后重试"

# 代码 bug → 停止
"AttributeError" → 停止，报告用户

# 支付失败 → 高风险
"Payment failed" → 停止，等待指示
```

### 🔍 第 3 层：HR 增强 - 替代 Agent 搜索

**位置**: [`hr_enhancement.py`](file:///Users/lin/Documents/trae_projects/OPC-Agents/opc_hr/hr_enhancement.py#L772-L790)

**触发条件**: 错误不可自动修复

**处理流程**:
```
任务失败
  ↓
发布 task_failed 事件
  ↓
HR 增强模块监听事件
  ↓
搜索外部替代 Agent（MCP GitHub/市场）
  ↓
找到替代？
  ├─ 是 → 推荐给用户 → 用户确认 → 招聘/培训 → 重新执行
  └─ 否 → 进入第 4 层
```

**代码逻辑**:
```python
def handle_task_failed(self, task_id, agent, department, description, error):
    # 搜索外部替代 Agent
    alternatives = self.search_external_agents(description, department)
    
    if alternatives:
        print(f"[HR 增强] 任务失败，已搜寻到{len(alternatives)}个替代 Agent")
        # 推荐给用户
```

**适用场景**:
- ✅ 当前 Agent 能力不足
- ✅ 需要更专业的 Agent
- ✅ 技能缺失

## ⚠️ 当前缺失的能力

### 执行时的能力发现集成

**问题**:
当前流程中，执行失败时**没有自动触发能力发现器**搜索新技能。

**当前流程**:
```
执行失败 → 搜索替代 Agent → 没有 → 通知用户
```

**应该的流程**:
```
执行失败 → 错误分类 → 能力不足 → 触发能力发现器
  ↓
搜索 ClawHub/MCP → 推荐技能 → 用户确认 → 安装 → 重新执行
```

### 改进建议

**增强 HR 增强模块**:
```python
def handle_task_failed(self, task_id, agent, department, description, error):
    # 1. 搜索替代 Agent
    alternatives = self.search_external_agents(description, department)
    
    # 2. 新增：触发能力发现器
    if is_capability_gap_error(error):  # 能力不足类错误
        self._opc_manager.event_bus.publish('capability_gap_detected', {
            'skill_name': 'unknown',
            'required_by': f'任务执行失败：{task_name}',
            'priority': 8,
            'task': description,
            'error': error,
            'from_execution': True  # 标记为执行时发现
        })
```

**好处**:
- ✅ 执行失败时自动搜索新技能
- ✅ 不仅搜索替代 Agent，也搜索替代技能
- ✅ 给用户更多选择
