✅ 代码 bug → 停止执行，需要人工干预
✅ 支付失败 → ⚠️ 高风险，等待指示

## ✅ Phase 2: 智能化功能（已完成 100%）

### 2.1 优先级智能推荐算法 ✅

**文件**: [`opc_manager/priority_advisor.py`](file:///Users/lin/Documents/trae_projects/OPC-Agents/opc_manager/priority_advisor.py)

**功能**:
- 3 维度评分算法：
  - ⏰ **截止时间（40%）**：今天=40 分，明天=20 分，本周=10 分
  - 🔗 **依赖关系（30%）**：关键依赖=30 分，一般依赖=15 分
  - 💼 **业务价值（30%）**：客户邮件=30，市场调研=20，文档=15
- 优先级映射：
  - 80-100 分 → CRITICAL (10)
  - 60-79 分 → URGENT (8)
  - 40-59 分 → HIGH (6)
  - 20-39 分 → MEDIUM (4)
  - 0-19 分 → LOW (2)
- 用户优先原则：用户明确指定时以用户为准

**测试结果**:
```
✅ 客户邮件（无截止） → 推荐 HIGH (9) - 业务价值 30 分
✅ 市场调研（有依赖） → 推荐 MEDIUM (5) - 业务价值 20 分 + 依赖 30 分
✅ 文档整理 → 推荐 LOW (3) - 业务价值 15 分
```

### 2.2 资源优化建议 ✅

**文件**: [`opc_manager/resource_optimizer.py`](file:///Users/lin/Documents/trae_projects/OPC-Agents/opc_manager/resource_optimizer.py)

**功能**:
- 实时监控：
  - CPU 使用率
  - 内存使用率
  - 磁盘空间
  - 进程信息（线程数、打开文件数）
- 健康度评分（0-100）：
  - excellent: 90-100
  - good: 70-89
  - fair: 50-69
  - poor: 30-49
  - critical: 0-29
- 优化策略：
  - CPU > 95%: 自动暂停低优先级任务（<3）
  - CPU > 80%: 提供优化建议
  - 内存 > 85%: 建议清理或升级
  - 磁盘 < 10GB: 建议清理

**测试结果**:
```
✅ CPU 96% → 自动暂停 2 个低优先级任务
✅ CPU 82% → 建议：减少并发数/暂停非关键任务
✅ 内存 88% → 建议：清理缓存/升级内存
✅ 健康度评分：85/100（good）
```
