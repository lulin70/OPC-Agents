## 一、版本定位

**0.1.0 = "可信可用"版本**

核心目标：让一个新用户能在10分钟内从 `git clone` 到获得第一份AI增强的专业文档。

三大信任断裂点：
1. 版本号混乱 → 用户不知道自己在用什么
2. 装不上跑不起来 → requirements.txt缺核心依赖
3. 配不上好体验 → 不知道怎么配API Key，只能用mock

## 四、0.1.0 验收标准

| # | 验收项 | 通过条件 | 验证方法 |
|---|--------|---------|---------|
| AC-01 | 一键启动 | 全新venv `pip install -r requirements.txt && streamlit run frontend/app.py` 无报错 | 实际执行 |
