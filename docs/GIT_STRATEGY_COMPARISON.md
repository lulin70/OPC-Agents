# Git 版本控制策略 - 完整对比表

> 📋 一目了然的 Git 策略指南 - 作为产品，什么应该放入 Git，什么不应该

---

## 🎯 核心原则对比表

| 维度 | ✅ 应该放入 Git | ❌ 不应该放入 Git |
|------|---------------|----------------|
| **目的** | 可复用的产品代码和文档 | 临时性、过程性、用户私有数据 |
| **稳定性** | 相对稳定，变化有版本意义 | 频繁变化，无版本价值 |
| **共享性** | 团队需要共享和协作 | 个人本地使用或敏感信息 |
| **生成方式** | 人工编写，有创意价值 | 自动生成，可重建 |

---

## 📁 文件类型详细对比表

### 1️⃣ 代码文件

| 文件类型 | 示例 | 是否提交 | 原因说明 |
|---------|------|---------|---------|
| Python 源代码 | `*.py` | ✅ **是** | 核心业务逻辑 |
| JavaScript | `*.js` | ✅ **是** | 前端交互逻辑 |
| HTML 模板 | `*.html` | ✅ **是** | 页面结构 |
| CSS 样式 | `*.css` | ✅ **是** | 界面样式 |
| Python 字节码 | `__pycache__/`, `*.pyc` | ❌ **否** | 自动生成，可重建 |
| Node 模块 | `node_modules/` | ❌ **否** | 依赖包，体积大 |

---

### 2️⃣ 配置文件

| 文件类型 | 示例 | 是否提交 | 原因说明 |
|---------|------|---------|---------|
| 配置模板 | `config.toml.sample` | ✅ **是** | 帮助用户快速部署 |
| 实际配置 | `config.toml` | ❌ **否** | 可能包含敏感信息 |
| 环境变量模板 | `.env.example` | ✅ **是** | 说明需要的变量 |
| 环境变量文件 | `.env` | ❌ **否** | 包含 API 密钥等敏感信息 |
| 依赖清单 | `requirements.txt` | ✅ **是** | 明确依赖版本 |
| 虚拟环境 | `venv/`, `env/` | ❌ **否** | 本地环境，体积大 |

---

### 3️⃣ 文档文件

| 文档类型 | 示例 | 是否提交 | 原因说明 |
|---------|------|---------|---------|
| 产品说明 | `README.md`, `README-EN.md` | ✅ **是** | 用户必读 |
| 架构文档 | `docs/architecture/*.md` | ✅ **是** | 技术参考 |
| 部署指南 | `docs/deployment_guide.md` | ✅ **是** | 运维必需 |
| 用户手册 | `docs/系统用户手册.md` | ✅ **是** | 使用指南 |
| API 文档 | `docs/API 文档.md` | ✅ **是** | 开发参考 |
| 变更日志 | `docs/CHANGELOG.md` | ✅ **是** | 版本历史 |
| Git 策略 | `GIT_*.md` | ✅ **是** | 重要规范 |
| 开发日报 | `phase1_dayX_report.md` | ❌ **否** | 过程记录 |
| 临时会议记录 | `*_meeting.md` | ❌ **否** | 过程讨论 |
| 过程计划 | `*_plan.md` | ❌ **否** | 已执行完毕 |
| 集成过程 | `wechat_*.md` | ❌ **否** | 技术探索过程 |

### 4️⃣ 数据文件

| 数据类型 | 示例 | 是否提交 | 原因说明 |
|---------|------|---------|---------|
| 数据库结构 | `migrations/*.sql` | ✅ **是** | 版本控制必需 |
| 数据库文件 | `*.db`, `*.sqlite` | ❌ **否** | 用户数据，频繁变化 |
| 数据库日志 | `*.db-shm`, `*.db-wal` | ❌ **否** | 临时文件 |
| 用户上传 | `uploads/` | ❌ **否** | 用户私有数据 |
| 任务数据 | `task_workspaces/` | ❌ **否** | 运行时数据 |
| 会话数据 | `sessions/` | ❌ **否** | 临时状态 |

### 5️⃣ 测试文件

| 测试类型 | 示例 | 是否提交 | 原因说明 |
|---------|------|---------|---------|
| 测试代码 | `tests/**/*.py` | ✅ **是** | 质量保证 |
| 测试配置 | `pytest.ini`, `conftest.py` | ✅ **是** | 测试环境配置 |
| 测试报告 | `test_results.xml` | ❌ **否** | 每次运行不同 |

| 测试日志 | `test_*.log` | ❌ **否** | 临时文件 |
| Mock 数据 | `tests/fixtures/` | ✅ **是** | 测试必需数据 |

## 📊 决策流程图

```
拿到一个文件 → 是否核心代码/文档？
                 ↓
        是 → ✅ 提交到 Git
        否 ↓
        是否用户数据/敏感信息？
                 ↓
        是 → ❌ 不提交（加入.gitignore）
        否 ↓
        是否可自动重建？
                 ↓
        是 → ❌ 不提交（构建产物）
        否 ↓
        是否有版本价值？
                 ↓
        是 → ✅ 提交到 Git
        否 → ❌ 不提交（过程文档）
```

## 🎨 快速参考卡片

### 🟢 绿色区域（必须提交）
```
✅ 源代码 (.py, .js, .html, .css)
✅ 测试代码 (tests/)
✅ 产品文档 (README, docs/architecture/)
✅ 配置模板 (*.sample)
✅ 迁移脚本 (migrations/)
✅ CI/CD 配置 (.github/)
```

### 🔴 红色区域（绝不提交）
```
❌ 数据库文件 (*.db)
❌ 敏感信息 (.env, secrets/)
❌ 用户数据 (uploads/, task_workspaces/)
❌ 过程文档 (phase1_*, wechat_*)
❌ 构建产物 (dist/, build/)
❌ 日志文件 (*.log)
```

### 🟡 黄色区域（需要判断）
```
🤔 配置文件 → 模板提交，实际配置不提交
🤔 测试报告 → 代码提交，报告不提交
🤔 文档 → 产品文档提交，过程文档不提交
🤔 Mock 数据 → 测试必需则提交
```

## 🔧 .gitignore 规则速查表

| 规则模式 | 匹配内容 | 示例 |
|---------|---------|------|
