## 🎯 快速导航

### 我是...

#### 新用户
1. 阅读 [README.md](../README.md) 了解项目
2. 按照 [INSTALL.md](../INSTALL.md) 安装
3. 开始使用！

#### 开发者
1. 查看 [CODE_MAP.md](../CODE_MAP.md) 了解代码结构
2. 阅读 [system_design.md](system_design.md) 了解系统设计
3. 查看 [phase1_implementation_plan.md](phase1_implementation_plan.md) 了解当前任务
4. 参考 [test_plan.md](test_plan.md) 编写测试

#### 产品经理
1. 阅读 [ui_enhancement_plan.md](ui_enhancement_plan.md) 了解产品规划
2. 查看 [product_review_meeting.md](product_review_meeting.md) 了解优先级
3. 跟踪 [phase1_day5_report.md](phase1_day5_report.md) 了解进度

#### 测试工程师
1. 阅读 [test_plan.md](test_plan.md) 了解测试策略
2. 查看现有测试：`tests/` 目录
3. 参考 [phase1_implementation_plan.md](phase1_implementation_plan.md) 了解待测试功能

#### 架构师
1. 深入阅读 [system_design.md](system_design.md)
2. 审查代码结构和设计
3. 指导技术实现
