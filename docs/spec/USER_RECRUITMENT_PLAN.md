# 真实用户招募计划

> **文档状态**: Sprint 1 产出
> **版本**: v0.3.0
> **日期**: 2026-06-19
> **负责角色**: PM
> **任务ID**: S1-T7
> **前置依赖**: S1-T4（Onboarding优化完成）

---

## 〇、招募目标

- **数量**: 3个真实用户
- **类型**: 一人公司经营者
- **试用周期**: 1周
- **核心验证**: 3个核心技能（email/finance/report）是否真正有用

---

## 一、用户画像

### 1.1 目标用户特征

| 维度 | 要求 |
|------|------|
| 身份 | 一人公司经营者 / 自由职业者 / 独立顾问 |
| 技术背景 | 非技术背景（不懂API Key是什么） |
| 业务需求 | 有邮件沟通、记账、报告生成需求 |
| 设备 | Mac 或 Windows 电脑（宽屏） |
| 时间 | 愿意投入1周试用，每天至少使用1次 |

### 1.2 排除标准

- 技术背景过强（开发者/CTO）— 他们不是目标用户
- 无邮件/记账/报告需求 — 无法验证核心技能
- 无法本地部署（无Python环境）— 需要远程访问方案

---

## 二、招募渠道

### 2.1 主要渠道

| 渠道 | 预期转化 | 备注 |
|------|---------|------|
| 朋友圈/微信社群 | 1-2人 | 发布试用邀请，附演示视频 |
| 独立开发者社群 | 1人 | 如独立开发者群、自由职业者群 |
| 个人网络 | 1人 | 直接邀请认识的创业者 |

### 2.2 招募话术

```
【试用邀请】OPC-Agents v0.3.0 — 一人公司AI助手

你是否每天都在：
📧 写跟进邮件 → 说一句话自动生成草稿
💰 记账 → 说一句话自动记录收支
📊 写报告 → 说一句话自动生成经营报告

我正在开发一款AI助手，帮你用自然语言完成这些事。
现在招募3位真实用户试用1周，你的反馈将直接影响产品方向。

要求：
- 一人公司经营者或自由职业者
- 愿意每天使用1次，反馈使用体验
- 试用免费，无任何费用

感兴趣请回复，我会提供安装指南和演示视频。
```

## 三、试用准备包

### 3.1 安装指南（非技术版）

**文档**: `docs/user/INSTALL_GUIDE_NON_TECHNICAL.md`（待创建）

内容大纲：
1. 什么是OPC-Agents（1段话）
2. 安装步骤（图文版，≤5步）
3. 如何获取API Key（链接+截图）
4. 首次使用引导（3个核心场景演示）
5. 常见问题FAQ

### 3.2 演示视频

**视频**: 3个核心场景演示（每个2-3分钟）

1. **邮件场景**: "帮我给张总写跟进邮件" → 生成草稿
2. **记账场景**: "帮我记一笔收入3000元" → 记录成功
3. **报告场景**: "帮我生成本月报告" → 生成报告

### 3.3 反馈收集表

**表单**: 每日简单问卷 + 试用结束深度访谈

每日问卷（≤2分钟）：
- 今天用了哪些功能？
- 遇到什么问题？
- 好用吗？（1-5分）

深度访谈（30分钟）：
- 3个核心技能哪个最有用？
- Onboarding流程顺畅吗？
- 会继续使用吗？会推荐给别人吗？
- 你愿意付费吗？

## 四、试用流程

### 4.1 准备阶段（Day 0）

- [ ] 确认3个用户已招募
- [ ] 发送安装指南 + 演示视频
- [ ] 确认用户能成功安装并配置API Key
- [ ] 建立反馈渠道（微信群或在线表单）

### 4.2 试用阶段（Day 1-7）

- **Day 1**: 用户首次使用，观察Onboarding完成率
- **Day 2-3**: 用户尝试3个核心场景，收集每日反馈
- **Day 4-5**: 用户自由使用，记录使用频率和场景
- **Day 6-7**: 深度访谈，收集整体评价

### 4.3 总结阶段（Day 8）

- [ ] 整理反馈到 `USER_FEEDBACK_REPORT.md`
- [ ] 识别P0问题（阻断使用）
- [ ] 识别P1问题（影响体验）
- [ ] 决策：继续v0.3.0方向 or 调整

## 五、成功标准

| 指标 | 目标 | 测量方法 |
|------|------|---------|
| Onboarding完成率 | ≥60% | Day 1观察 |
| 3核心技能使用率 | ≥80%用户使用过全部3个 | 每日问卷 |
| 用户满意度 | ≥3.5/5 | 深度访谈 |
| 继续使用意愿 | ≥2/3用户愿意继续 | 深度访谈 |
| 推荐意愿 | ≥1/3用户愿意推荐 | 深度访谈 |
| 付费意愿 | ≥1/3用户愿意付费 | 深度访谈 |

## 六、风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 招募不足3人 | 中 | 高 | 扩大渠道；降低门槛（提供远程访问） |
| 用户无法安装 | 中 | 高 | 提供远程协助；准备Docker一键部署 |
| API Key配置困难 | 中 | 中 | S1-T4已优化Onboarding；提供视频指导 |
| 用户反馈3技能不够 | 中 | 中 | 记录需求；评估是否解冻更多技能 |
| 用户反馈产品无用 | 低 | 高 | 诚实面对；可能需要重新定义产品方向 |
