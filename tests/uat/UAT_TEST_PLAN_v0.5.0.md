## 一、测试目标

### 1.1 总体目标

通过 2 周用户接受测试，验证 OPC-Agents v0.5.0 在 5-10 名种子用户真实场景下的可用性、价值性、商业可行性，产出 PMF 早期信号判断与 v0.6.0 路线图输入。

### 1.2 具体目标

| # | 目标 | 验证方式 |
|---|------|---------|
| G1 | 验证 5-10 名种子用户的真实使用场景可走通 | 18 个核心场景测试用例执行 |
| G2 | 验证 6 大用户类型的核心场景可用性 | 30 个测试用例（每类型 5 个）执行 |
| G3 | 验证 5 大商业指标采集准确性 | 自动埋点 + 数据库抽样核对 |
| G4 | 验证 3 大体验指标评分流程 | 每日问卷 + 反馈评分 UI 触发验证 |
| G5 | 验证 Onboarding 流程非技术用户可独立完成 | Day 1 现场观察 + 完成率统计 |
| G6 | 验证 UI_DESIGN_v0.5.0 的 3 个原型可用性 | E2E 5 个场景验证 |
| G7 | 验证产品定位矛盾解决路径 | 飞轮路径组合验证 + 解冻决策依据采集 |

### 1.3 与 E2E 自动化测试的关系

| 维度 | E2E 自动化测试 | UAT 用户接受测试 |
|------|---------------|------------------|
| 执行者 | Playwright 模拟脚本 | 真实种子用户 |
| 场景 | 199 个代码路径 | 18 个真实场景 |
| 数据 | Mock 数据 | 用户真实业务数据 |
| 反馈 | Pass/Fail 二元结果 | 满意度 + 体验评分 + 文字反馈 |
| 价值 | 验证代码不崩 | 验证产品有用 |

## 二、测试范围

### 2.1 In Scope

- 6 大用户类型 × 3 核心技能（email/finance/report）= 18 个核心场景
- 6 大用户类型 × 5 个测试用例 = 30 个测试用例
- 5 大商业指标采集（activation/upgrade/flywheel/payment/nps）
- 3 大体验指标采集（conversation_naturalness/result_satisfaction/proactive_service）
- UI_DESIGN_v0.5.0 的 3 个原型（P5.1 反馈评分 / P5.2 安装引导 / P5.3 同意弹窗）
- Onboarding 流程（5 步图文版 + 3 个 AI 后端选项）
- 飞轮路径组合验证（task+finance+report / crm+email+report）

| 排除项 | 原因 | 推迟到 |

| opc_manager 子包化 | 不影响用户使用 | v0.6.0+ |
| SEC-5-02 MCP HTTPS 强制 | 外部技能扩展阶段 | v0.6.0 |
| 飞轮数据闭环真实流转 | v0.5.0 仅采集基线 | v0.6.0+ |

| 多平台分发扩展 | v0.5.0 仅 Mac/Windows | v0.6.0+ |
| 国际化扩展增强 | v0.5.0 验证三语可用 | v0.6.0+ |

| 周次 | 主题 | 时长 | 关键活动 |
|------|------|------|---------|

### 3.3 数据采集方式

| 采集方式 | 频率 | 内容 | 存储 |
|---------|------|------|------|
| 自动埋点 | 实时 | activation/upgrade/flywheel/payment/nps/experience 6 类指标 | 本地 SQLite |

| Week 2 访谈 | Day 14 | 60 分钟终期访谈 + NPS 评分 | 录音 + 文字记录 |

### 3.4 缺陷分类标准

| 级别 | 定义 | 响应时效 | 处理方式 |
|------|------|---------|---------|
| P0 阻断 | 无法安装 / 无法启动 / 数据丢失 / 安全漏洞 | 24 小时内修复 | 立即修复 + 用户通知 |
| P1 体验 | 功能不可用 / 流程卡顿 / 文档错误 | 1 周内修复 | 进入 v0.5.0 迭代 backlog |
| P2 建议 | 优化建议 / 新功能需求 | v0.6.0 评估 | 进入 v0.6.0 路线图输入 |

### 5.2 Day 1：Onboarding（W9 周一）

| 时段 | 用户任务 | PM/Tester 任务 |
|------|---------|---------------|
| 上午 | 接收安装指南 + 演示视频 | 发送物料 + 答疑 |

## 九、风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 招募不足 5 人 | 中 | 高 | 扩大渠道（朋友圈/社群/知识星球）；降低门槛；提供远程访问方案 |
| 用户无法独立安装 | 中 | 高 | 提供远程协助；优化安装引导；准备 Docker 一键部署；Moka AI 免 API Key 备选 |
| API Key 配置困难 | 中 | 中 | v0.5.0 优化 Onboarding；提供视频指导；Moka AI 网关默认免配置 |
| 用户反馈产品无用 | 低 | 高 | 诚实面对；可能需要重新定义产品方向；触发 v0.6.0 情景 C |
| LLM 后端不稳定 | 中 | 中 | Ollama + OpenAI + Moka AI 三路 fallback；监控响应时间 |
| 数据采集失败 | 低 | 中 | 埋点测试 + 备用方案（手动问卷）；每日核对数据完整性 |
| 用户中途退出 | 中 | 中 | 激励机制（免费 1 年专业版）；保持每周沟通；提供技术支持 |
| 反馈质量低 | 中 | 中 | 每日问卷 ≤2 分钟；访谈提纲结构化；提供示例反馈 |
| 飞轮路径未形成 | 中 | 中 | Day 8 引导组合使用；提供飞轮路径演示视频 |
| 三语切换异常 | 低 | 低 | 发布前 E2E 三语切换测试；备用方案仅支持中文 |
